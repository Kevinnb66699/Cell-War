> 重跑：`<godot> --headless --path game --script res://tests/mech_card_value.gd`
> 口径：**只估即时 + 永久技能卡（50 张）**。事件卡已剔除（小组决定删事件）。
> 原则：**每卡 = 杠杆向量，各杠杆用自然单位，不通一成能量当量。**

## 为什么是杠杆向量，不是能量当量

`MechValue` 的哲学（2026-09）：杠杆各自成维、故意不通一——因为「几格地盘 = 几能量」「1 记忆 = 几能量」**本身就是平衡问题，不是给定量**。跨杠杆汇率是**要标定的东西**，不是可假定的先验。
早前一版把 `TILE=2.0/SOLID=5.0/ANTIGEN=1.0` 压成单一"能量当量"并据此跨杠杆排序，是**概念回退**，已废弃。

## 杠杆与其自然单位（对齐 MechValue）

| 杠杆 | 单位 | 涵盖 |
|---|---|---|
| `supply` 能量/供给 | 十分位能量/回合 | 无氧供给、有氧收入、能量损益、转移 |
| `land` 地盘 | 格 | 净化解 / 定殖转癌 / 拆地 / 防守地盘 |
| `solid` 固化 | 计数/提前回合 | 固化推进、拆固化、固化冻结 |
| `atk` 攻击 | 十分位伤害/判定 | 攻击 EV、伤害值、标记、斩杀 |
| `def` 防御 | 十分位减损 | 减损、免死、防大成功 |
| `ag` 抗原/记忆 | 记忆点 | 免疫升级进度 |
| `mov` 机动 | 步/迁移 | 传送、跳步 |
| `cost` 费用 | 十分位省费 | 迁移/技能费减免（≠ 直接能量） |
| `draw` 抽卡 | 张 | 卡经济（价值本身待实测） |

## 关键观察（模型先验，非实测）

1. **癌症进攻杠杆几乎缺席**：`atk` 池 12 张里，癌方只有 `乳酸酸化`（消耗相邻免疫能量）；其余都是**免疫**的伤害/标记/EV 卡。这是「癌方无走过去攻击的对称机制」在卡牌层的直接体现——与意图癌胜率平台的根因同源。
2. **`ag`（记忆）是稀缺杠杆**：仅 3 张推（局部吞噬 / 效应记忆形成 / 抗体亲和力成熟），全免疫侧。记忆是免疫升级进度，属高杠杆稀缺资源 → `效应记忆形成`（II 级）一卡同时推 ag+supply，**疑似低定级/超值**，是同级里最亮的离群。
3. **免疫卡横跨多个进攻杠杆**，癌卡集中在 `supply/cost/mov/def`——即免疫卡多为"改变局面"（atk/land/solid），癌卡多为"巩固资源"（supply/cost/def）。两头打法错位：免疫进、癌方守。
4. **`land` 池里 放疗(≤10格连片) 远超 局部吞噬(1格)**，同杠杆内部规模差距最大——单杠杆内最该看的一张。
5. 癌方 `supply` 是规模杠杆：GLUT1/RAS 的收益跟细胞数×回合，越滚越大，跟免疫 `supply` 卡（+0.5~0.8/次）量级相当但更吃场面。

## 这是什么、不是什么

- **是**：可复现的**杠杆分解 + 单杠杆内数值排序**，跨杠杆张力显式列出（留给实测）。
- **不是**：跨杠杆总评、胜率、精确概率。`q` 是先验估计 + 参考单位选择；`basis` 里的规模/持续要有人按场面乘。

## 单杠杆归一化（已落地）

每杠杆一个**参考动作/单位**，卡推量折算成 `q = ×参考倍数`，**只在单杠杆内按 q 排序，跨杠杆不排**。`q=null`（如免死一次）标「定性」排最后。**q 是单实例倍数**，不是整局总量——持续/规模（每回合/规模×细胞×回合）放 `basis`，不折叠进 q。

**单杠杆内量化判读：**
- **land**：放疗(10×) ≫ 炎症性趋化(3×) > 溶酶体/克隆增殖等(2×) > 局部吞噬/癌症转移(1×)。
- **cost**：组织驻留/癌症干性(20×，basis=每回合) ≫ 组织巡航(10×) > 杂项(0.2~0.5×)。每回合型靠 basis 标清。
- **supply**：癌症干性复活(4×，情境) > GLUT1(0.75×/细胞·回合，规模杠杆越滚越大) > 免疫各 0.5×。
- **atk**：吞淋巴体成熟(2×，巨噬) > 抗体依赖(1.5×) > 乳酸酸化(1.4×，癌方唯一攻击卡) > EV 类(0.17~0.34×/判定)。
- **ag**（记忆）：仅 3 张全免疫侧——稀缺杠杆，效应记忆形成(II 级)一卡同时推 ag+supply，同级最亮离群。
- **def**：BCL-2 免死不可量化（定性）；其余 1~2×。
