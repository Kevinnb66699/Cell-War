# 单卡估值表（能量当量）· 平衡研究

> 生成：`game/tests/mech_card_value.gd`（headless，遍历 `CWCardData.CARDS` 断言全覆盖）。
> 重跑：`<godot> --headless --path game --script res://tests/mech_card_value.gd`
> 口径：**只估值即时 + 永久技能卡（50 张）**。事件卡已剔除（2026-09-20 小组决定删事件、对局都关事件）。

## 这是什么、不是什么

- **是**：每张卡折算成**能量当量**（1.0 = 1 能量）的模型化估计，用于**同池/同级内比较**，找超值/亏值卡。是平衡研究的先验，也是训练的奖励塑形/特征。
- **不是**：实测胜率、精确概率。绝对数值依赖下面的换算常数，**相对排序**才是结论。

## 换算常数（平衡研究要讨论的对象，可调）

| 常数 | 值 | 依据 |
|---|---:|---|
| `TILE` | 2.0 | 1 格癌性组织 = 1 胜利进度 + 无氧供给边际（回现）+ 扩张成本递减 |
| `SOLID` | 5.0 | 1 格固化 = 2 进度 + 复活点 + 全图供给加成 + 不可净化 |
| `ANTIGEN` | 1.0 | 1 抗原记忆 = 免疫升级进度 |
| `ROUNDS` | 7.0 | 持续效果折现（15 回合制，按第 8 回合拿到） |
| `DRAW` | 1.5 | 一次抽卡的期望价值 |

## 关键发现

1. **免疫卡估值系统性高于癌卡**：免疫顶卡 10.5（免疫记忆库/效应记忆形成）vs 癌顶卡 5.6（GLUT1）。免疫 X 级池大量 5~10，癌池普遍 1~5.6。与 mech_timeline「当前规则免疫占优」的发现互证。**但要先审视换算常数**（TILE/ANTIGEN 偏高会放大免疫地盘/抗原类卡）。
2. **同级离群卡**（平衡最该看的）：
   - **效应记忆形成（II 级，10.5）**——一个 II 级卡价值媲美最好的 X 卡，疑似**低定级/超值**：每回合首次净化 +1 抗原 + 0.5 能量，复合滚雪球极快。
   - **组织驻留（I 级，7.0）**——I 级池里远超同侪（次高 3.5），每回合 2 次健康迁移免费，早期发育提速巨大。
   - **炎症性趋化（III 级，6.9）**、**放疗（X，10.0）**、**基质重塑（X，9.0）**——地盘转化类大卡在高级别合理，但幅度值得核对。
3. **癌卡扁平且偏弱**：1.0~5.6 无极强卡，缺一个能改变战局的「大招」；癌方强在机制（定殖/无氧/固化）而非卡牌。这与「癌方赢靠机制滚雪球不靠卡」的时间线结论一致。
4. **权重×价值**（出现频率 × 单卡价值）更值得看：癌方 克隆增殖 w5(I期)/4.0、基质硬化 w2→w5(III期)/2.5 又高价值又高频，是癌卡的实际支柱。
