# Cell War 联机操作说明

给玩的人看的。技术设计在 [联机设计_2026-09-02](联机设计_2026-09-02.md)，这里只讲怎么用。

文档里的数字都是从代码里读的，不是约定俗成——改了代码这份也要跟着改。

---

## 一、拿到游戏

客户端包在 **[GitHub Releases](https://github.com/Kevinnb66699/Cell-War/releases)**，
每次发版一个 tag（形如 `client-2026-09-09-10`），**取最新的那个**。

| 系统 | 下载 | 启动 |
|---|---|---|
| Windows | `CellWar.exe`（约 95 MB） | 双击。首次可能被 SmartScreen 拦，选「更多信息 → 仍要运行」 |
| macOS | `CellWar.zip`（约 63 MB） | 解压后双击。包已签名 |

**服务器和客户端必须同版**。版本不符时连不上，会看到「客户端版本与服务器不符，请更新游戏」——
下最新的包就行。

> 小改动（调数值、改特效）会走热更新：启动时自动下载几十 KB 的补丁包，
> 屏幕上闪一下「正在更新…」。**新增功能仍然要重新下包**——
> 那时候会提示「有新版本需要完整更新，请到 GitHub Releases 下载新客户端」。

---

## 二、连上服务器

主菜单 → **联机对战**，第一页要填两样：

- **昵称**：最长 **12 个字**。不唯一，重名不冲突。
- **服务器地址**：默认 `124.221.78.13:8611`，一般不用改（改它是为了内网自测）。

按 Esc 回主菜单。

---

## 三、大厅

连上之后进大厅，三件事：

- **公开房间列表** —— 分两栏。上面是**能坐进去的**，每行「房间码 · N 人局 · 已坐/总数 · 每步计时 · 房主」；
  底下「**进行中 · 可观战**」那一栏是正在打的局，每行写「观众 N/8」。点一行进去。
- **建房** —— 自己开一局，见下一节。
- **输房间码** —— 别人把码发给你时用。码是 **6 位**，字母表里**没有 I、O、0、1**（免得看串）。

看到「（暂无公开房间）」就是这会儿没人开公开房，可以自己建一个。

---

## 四、建房

四行，左右方向键拨：

| 行 | 可选 | 说明 |
|---|---|---|
| **人数** | 2 / 4 / 6 | 免疫和癌症**对半分**，显示成「6 人（3 免疫 · 3 癌症）」 |
| **每步计时** | 不限 / 30 秒 / 60 秒 / 90 秒 | 每次轮到你做决定的时限。超时**自动代打**，不是判负 |
| **可见性** | 公开（进大厅列表）/ 私密（凭房间码） | 私密房只能靠房间码进 |
| **世界事件** | 开 / 关（整局不触发） | 关掉就是纯规则局 |

服务器正在发新版时建不了房，会看到「**服务器维护中，暂不能建房**」——
等几十秒，切完版就好了。

---

## 五、等待室

- **点空席坐下**。座位按阵营分成两栏，坐哪边就是打哪一方。
- 坐下后按 **准备**（再按一次取消准备）。
- **房主**额外能做三件事：给空席**放 AI**（新手 AI / 专家 AI）、**踢出**某人、**开局**。
- 全员准备好会提示「全员就绪，等房主开局」。

没坐下的人显示在「未入座」那行。**开局后他们自动进入观战** ——
看得到整块棋盘和公开日志，看不到任何人的手牌。

空房 **10 分钟**没人自动关掉。

---

## 六、对局中

右上角两个数：

- **剩 N 秒** —— 这一步的倒计时（建房时选的「每步计时」；选「不限」就不显示）
- **延迟 N ms** —— 你到服务器的往返延时

其它：

- **聊天：2026-09-10 起暂时关掉了，这一版看不到聊天页**。原因是实战里冒出三条毛病
  （从小横条点开之后关不掉、点框外空白处不收、打字打到 L 会弹出对局日志），
  修好之前先不放出来。服务器那半边照常收发，不影响别的功能。
  以下是它开着时的样子，留着备查：左上角那块地是「日志 / 聊天」两个标签页，点标签切换。
  发言可选**全体**或**己方**（观众自成一档，只跟观众互通），Tab 或点右上角那两个字换。
  一条最长 **60 字**。
  别人说话时你没在看聊天页，左上那条小横条会临时切过去显示最近两条，几秒后自己切回日志。
  **不会弹窗、不抢焦点、不发提示音** —— 你可能正在选迁移落点。
- 席位上会标 **离线** / **AI 代打中**。
- **暂停菜单只有「离开房间」** —— 联机局不能存档、不能读档、不能改规则。
- 掉线时整个棋盘会盖一层遮罩，写「连接断开，重连中…」。

### 投降

同阵营发起投降要**投票**：本阵营**在线的真人**都要投，**30 秒**内没投够就算否决。
AI 队友一律同意。单人一方发起即生效。

## 七、掉线了会怎样

设计上假定网络会抖，所以掉线不等于输：

| 时间 | 发生什么 |
|---|---|
| 客户端每 **5 秒** 发一次心跳 | 正常 |
| 服务器 **20 秒** 没收到任何报文 | 判你掉线，席位**保留并标「离线」** |
| 掉线期间轮到你 | 有计时就等到时限（留给你重连），没计时就立刻由 AI 代打 |
| 客户端每 **3 秒** 自动凭令牌重连 | 接上就回到原座位，那一问会重新问你一遍 |
| 掉线满 **2.5 分钟** | 视同主动离开，不再计入投降票 |

所以**断网了别急着关游戏**——挂着就会自己接回去。

真正会丢局的只有一种：**服务器非排空重启**（机器崩了、手工重启）会丢掉所有房间。
正常发版走的是「排空」，最后一局打完才切版，不影响在打的人。

## 八、看到这些字是什么意思

| 屏幕上写的 | 意思 | 你该做什么 |
|---|---|---|
| 客户端版本与服务器不符，请更新游戏 | 你的包和服务器不同版 | 下最新的 Release |
| 有新版本需要完整更新，请到 GitHub Releases 下载新客户端 | 这次改动热更不了 | 下最新的 Release |
| 服务器维护中，暂不能建房 | 正在发新版 | 等几十秒 |
| 维护中：暂不能建新房 | 同上（大厅上的横幅） | 等几十秒 |
| 连接断开，重连中… | 网络断了 | 什么都别做，等它自己接 |
| 正在更新… | 在下热更补丁 | 等，几秒钟 |
| 上次的更新没能正常启动，已回退到原版 | 补丁装崩了，已自动回滚 | 照常玩；告诉开发 |
| 这局的观众满了，等下一局吧 | 一个房间最多 8 个观众 | 等这局打完，或换一局看 |

## 九、看回放

主菜单 → **对局回放**。两栏，左右方向键或点标题切换：

| 栏 | 是什么 |
|---|---|
| **本机** | 这台机器手上有的：单机局自己存的、联机局打完服务器推给你的、你从服务器下过的。最多留 **20** 份 |
| **服务器** | 服务器上最近 **50** 局，**包括你没参与的**。切到这一栏才会连服务器（地址用你在「联机对战」填的那个） |

- 一屏 5 行，**上下方向键选到头会自己翻页**，滚轮也翻；第几页写在标题下面那行。
- 本机那栏一行写「时间 · 几人局 · 打了几回合 · 谁赢」；服务器那栏用「#编号 · 房间码」认局
  （目录新的在前，所以位置本身就是时间）。
- 点一行开看。服务器那份会**顺手存到本机**，之后不用联网也能再看。

### 看的时候能做什么

底下那条是播放控制：**◀◀ 快退 · 暂停 · ▶▶ 快进**，中间的进度条可以直接拖，
右边是倍速（点一下换一档）。键盘：**空格**暂停 / **← →** 快退快进 / **↑ ↓** 换倍速。

**回放里看得到所有人的手牌** —— 局面是在你机器上重算出来的，没有谁在藏东西。

按 **Esc** 弹菜单，那一项叫**退出回放**（不是「离开房间」——
回放不是一局，没有席位，也没人替谁打）。

## 十、已知限制

这三条是**设计上就接受的**，不是 bug：

1. **服务器非排空重启会丢掉所有房间。** 正常发版不受影响（走排空）。
2. **AI 思考时整个服务器会停顿。** 专家 AI 最长堵约 1 秒，别的房间那一秒也不动。
   已经做了缓解（不会因此把人判掉线），根治要把 AI 决策挪到工作线程，还没做。
3. **没有账号，所以防不了冒名。** 昵称随便填、不唯一。

v2 清单里**还没做**的：战绩、排行榜、账号系统、「热座（同机两人）+ 远端混合」、网页版。
（联机观战、房内聊天、回放已经在 2026-09-09 上线，见上面几节。）

观众目前**只能看公共视角**：整块棋盘和公开日志，看不到任何人的手牌，也不能切到某个人身后看他的牌。
那一条是团队明确记下来**暂时不做**的。

（单机那边另有一个观战档：对局配置面板「我的阵营」拨到「观战」，全 AI 互打你在旁边看。
那和联机观战不是一回事。）

## 十一、给开发的两条

- 发版流程见 `tools/deploy_server.sh`（服务器）与 `tools/publish_release.sh`（客户端包）。
  **发版前必须先把 `PatchState.BASE_BUILD` 改到 `date +%Y%m%d%H%M`**，否则发版脚本第 ⑤ 项会拦。
- 线上验收跑 `tests/net_live.gd -- url=ws://124.221.78.13:8611`，八个场景。发版后跑一遍再通知大家。
