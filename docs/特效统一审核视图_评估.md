# 粒子 / 演出特效「统一审核视图」—— 可行性评估（定稿）

Kevin 的原话：「评估维护一份游戏中所有粒子特效展示的统一视图，用于人工审核特效是否预期的可能性」。
本稿只答**能不能做、怎么做最省、代价与坑**。仓库零改动、没跑过 git；出图与探针全在 `scratchpad/` 下。每个事实带出处。

> 本稿已过反驳者复核，8 条意见全接受并逐条重核（含一条**实质翻案**：GD / C# 的 `revive_*` 没岔）。改动清单见文末**附录 D**。

**结论三句**

1. **可行，而且已经做掉一半。** 不是造新壳，是把 `game/tests/preview/` 下 33 个既有预览脚本（实测 33 个 `.gd`）收口成「一张表 + 三道自动闸 + 一页对照」。其中 13 个特效出图脚本今天一趟 **37.4 秒出 44 张 PNG、零报错**（`fx_readerB.md` §4.3 实测）。
2. **目录能零登记，可审的图不能。** 目录自动（差集闸，我重跑复现）；但**空棋盘上的特效人根本审不了**——这是两版设计稿共同的硬伤。舞台（刷哪些格是癌组织、摆哪几只细胞）是设计意图，天然逐 kind 手写。
3. **最小可用 4.5~5 人日**，覆盖 41 种条目驱动特效，一趟 20~30 秒。

  `play()` 第一行 `if not DURATION.has(kind): return`（`skill_fx.gd:154-155`）——**不在表里的 kind 根本演不出来**，所以那张表是权威目录，不是人工登记。

## 2. 主路：(c) 自动截图对照页

### 2.1 默认走 L2 桥，而且桥要在三字段之外补两个（我实测订正）

两版探针都只调裸 `CWSkillFx.play`（L1）。定稿默认走 `CWUIBridge`：`CWUIBridge.new()` 设 `board` / `skill_fx` / `erosion` 就能 `show_fx`（先例 `game/tests/headless_test.gd:3387-3391`），这样 `ui_bridge.gd:1128-1155` 的**轴坐标→棋盘像素换算**与 `*_body` / `r` 补算第一次被眼睛看到——那 28 行今天只有无头测试验数值。

**但那三个字段会静默吞掉 `immune_attack` 与 `chomp`。** 探针实测的是 `board` + `skill_fx` 两字段；`erosion` 与这两种无关，补上也照样吞。 `show_fx` 对这两种早退：一条要 `attack_animation.is_valid()`（`ui_bridge.gd:1117`，字段声明 `:56`，默认空 Callable），一条要 `chain_fx != null`（`:1122`，字段 `:54`）。缺了就**什么都不画、不报错**。
我写了探针 `scratchpad/fxS/game/tests/preview/probe_l2.gd` 真渲染跑了一趟（Godot 4.5，Vulkan，`timeout` 包住，退出码 0）：

```
attack_full  immune_attack  补齐后  变化像素(采样)=786
chomp_full   chomp          补齐后  变化像素(采样)=556
attack_3field immune_attack 未补齐  变化像素(采样)=0
chomp_3field  chomp         未补齐  变化像素(采样)=0
```

两处措辞要照实说（原稿印的是探针自己的 print 标签，不准）：
- **数字是隔像素采样**：`probe_l2.gd:100-101` 的 `_diff` 两个 `range` 都以步长 2 走，786 / 556 约为绝对变化像素的 1/4；「0」是真 0（同样采样下一个都没变），不影响结论。
- **「5 字段 / 3 字段」是标签，实际那一跑设了 4 个**：`probe_l2.gd:75-80` 只设 `board` / `skill_fx` / `chain_fx` / `attack_animation`，没设 `erosion`（这两种本来也用不上它）。

⇒ 期 1 的桥在三字段之外**必须补 `chain_fx` 与 `attack_animation`**（后者照 `CWMatch._play_attack_animation`（`match.gd:1729-1737`）写一个注入 Callable），且**这两种至此已真跑过、不再是纸面覆盖**。

### 2.2 舞台：可审 / 不可审的分界，必须承认它要手写

两版探针的出图（`fxD/sheet/s_card_blood.png`、`fxD/shots/g3_card_blood_1.png`）棋盘上**零癌组织、零细胞**，【血供掠夺】那口「多个癌细胞同时吸收血色能量」（`skill_fx.gd:41`）只剩几粒粉像素浮在空格上——**没法判断是不是预期**。既有 `preview_card_fx.gd` 出的同一种（`fxD/shots/cardD_card_blood.png`）有三块癌组织 + 三只黑色素瘤，能审。差别就在 `_paint`（刷组织，定义 `preview_card_fx.gd:61`）/ `_cell`（摆细胞，`:66`）—— card_blood 那一支的调用在 `:154-158`，它**逐 kind 手写，也只能手写**。

⇒ **「零登记」的口径改成：目录零登记，舞台要登记。**

**顺带一条只有真跑才看得见的**：`immune_attack` / `chomp` 由演出层**代画双方胞体**，真局里靠 `chewing_cid` 与 `owns()` 把真身藏起来（`match.gd:1620-1623`、`attack_fx.gd:30`）。我的探针没藏，出图就是两只重叠的细胞。⇒ 这两种的舞台要么不摆真身、要么照抄那两行。

### 2.3 三道闸

| 闸 | 做法 | 挡住什么 | 自动 / 手工 |
|---|---|---|---|
| ① 目录差集闸（**双向**） | 静态扫 `game/scripts/core/` 的 `fx("…")` 产生点 ↔ `DURATION` 键互减；**`{chomp, immune_attack}` 进显式白名单**（这两种走 `ui_bridge.gd:1116-1125` 早退分派，本就不该进 `DURATION`），白名单之外任一边多出才红 | 新 kind 没进表；表里有 kind 已无人产生 | 全自动 |
| ② 目录 ∧ 舞台 双闸 | **按 kind（不是按 handler）**解析 `_draw()` 的 match（`skill_fx.gd:241-264`）取键，要求 fixture ⊇ 这一集；**kind 在目录里但没有舞台 = 黄灯**。**判定只做黄灯提醒、不做红灯**（理由见下） | 「画在原点的假图」＋「空棋盘假图」 | 半自动（分叉要人读一遍），舞台手写 |
| ③ 像素基线闸 | **解码后逐通道**比像素，每个 kind 各记自己的基线数，页顶只列「变了的 N 种」 | 效果被改坏 / 悄悄没了 | 全自动，基线人认一次 |

闸①我原样重跑复现：产生点 **29** 个互异 kind，`DURATION` **27** 键，正向差集恰好 `{chomp, immune_attack}`，**反向为空**。⇒ **这两个就是上面那条白名单**，不写进去闸①第一天就红、且永远红（原稿漏了，已补）。
闸②的前提要收紧（原稿写「kind→handler 一一对应、机器可读」，**不成立**）：27 个 kind 只落到 **23** 个 handler —— `:255` `_card_area` 吃 `card_radiation` / `card_storm` / `card_inflammation`、`:256` `_card_hit` 吃 `card_granule` / `card_acid` / `card_cascade`，两者都再收 `kind` 参数在函数体内分叉（签名 `:565` / `:580`；例如 `_card_hit` 里只有 `card_cascade` 那支读 `tiles`，`:588-589`）；`card_repair` / `card_degrade` 还是内联调 `_shield` / `_dust`（`:260` / `:262`）。按 handler 取键拿到的是那三个 kind 的**并集**，会对个别 kind 报假缺键。⇒ 闸②按 kind 取键、分叉处人读一遍，**期 1 的人日别按纯静态分析估**。
闸③有两个坑：capture 探针的 `_diff` 用原始字节 + `i += 3` 步进（`fxD/game/tests/preview/fx_sheet.gd:64-73`），RGBA8 下是**通道错位**（Vulkan 出 RGB、OpenGL 出 RGBA，`fx_readerB.md` §7）；阈值也不能一刀切——探针里 `adhesion` 只有 28 差异像素，被 `MIN_PX=40` 误报成红。

### 2.4 「预期」的正本 = 选稿页，不是上一版截图

`tools/art-preview/` 是团队选稿页，本身带目录 + 播放 / 重播 + 0.5×/1×/1.5× + 时间轴 + 显示棋盘（`tools/art-preview/index.html:16,18` 实测），而 `skill_fx.gd:14-46` 的字段表里**每种 kind 都注明复刻的是哪一份选稿哪一版**。⇒ 对照页**左栏真渲染、右栏选稿**，并印出该 kind 的选稿出处，以及两条**刻意的偏移**（否则会被当 bug 报）：选稿里 0.65 秒的起手静止一律去掉（`skill_fx.gd:9`）；卡牌粒子时长 = 选稿收场时刻 − 0.4 s（`CARD_LEAD`，`skill_fx.gd:109`）。
基线 PNG 是**第二正本**：只答「变没变」，答不了「对不对」。
脚注（不是待决问题）：选稿 `card-catalog.js` 16 张卡 vs 实装 14 个 `card_*`，差的两个 `skill_fx.gd:43` 已写明——「抗体依赖细胞毒作用复用 antibody（单目标）、糖酵解爆发复用 anaerobic」。

### 2.5 节奏用 12 fps 帧带，不做 GIF

`_draw()` 把 t 按 `PIX_FPS = 12` 量化（`skill_fx.gd:50,239`），**比 12 fps 更细的步进画面上根本不动**，所以一条完整帧带张数有限（最长的 `homing` 2.9 s = 35 格）。疑似有问题的 kind 出一条帧带即可，不必做交互壳、不必外挂 ffmpeg。

### 2.6 出图前显式置位两个开关

`CWSettings.dice_anim` 与 `teleport_anim`（`game/scripts/ui/cw_settings.gd:15,16`）为 false 时整只特效不播。脚本开局必须显式置真**并把当前值印在页面上**，否则「没看见」会被误判成 bug。

## 4. 硬坑

1. **不能 `--headless`，而且会死循环**：`root.get_texture().get_image()` 返 null → 存图失败 → 脚本不前进，实测被 timeout 在 5 分整砍（`fx_readerB.md` §7）。⇒ **所有出图命令必须包 `timeout`**（我这一跑也包了）。
2. **「进 CI」今天是空词**：仓库没有 `.github/workflows`（实测不存在），`tools/run_tests.sh` 里 `grep preview` 零命中，且真渲染要显示设备。现实口径 = 本机手跑，挂进提交前流程。
3. **缺 fixture 静默出假图**：`preview_card_fx.gd:98` 的 `var data := {}` + `_scene()` 无 default 分支（实测 `_:` 零命中），未登记的 kind 一路走到 `fx.play(kind, {})`，而 `_v()` 缺键返 `Vector2.ZERO`（`skill_fx.gd:274-275`）——正好落在格心，肉眼会读成「这个效果比较含蓄」。靠闸②解。
4. **可复现性分两种**：`fx.sync(t)` 一次性推到点的可复现（`preview_card_fx.gd:160-161`，实测三张逐字节相同）；`sync(delta)` 每帧走真实 delta 的不可复现（`preview_skill_fx.gd:115-119`）。⇒ 像素闸只能建在前一种上，收口时把后一种改掉，是几行。
5. **GD / C# 内核 kind 今天是齐的**（原稿此处写反，已订正）：`revive_immune` / `revive_cancer` C# 侧也在发 —— `core/CellWar.Core/PhaseRules.cs:360` 一个三目按阵营发这两种，注释里连 GD 行号 `cw_world.gd:297/367` 都对上了。全仓 `Stage.Fx(` 共 31 处（`BoardRules` / `CardRules` / `CellRules` / `PhaseRules` / `PlacementRules` / `SkillRules`，定义在 `core/CellWar.Core/Stage.cs:40`），取 kind 去重 **29 个，与 GD 侧 `game/scripts/core/` 的 29 个逐字相同，双向差集都为空**（我自己重跑复现）。⇒ 这不是坑，是**闸①该顺手扩的一条**：今天两边齐，加上 C# 扫描是防以后单边加 kind（注意闸①现在只扫 `game/scripts/core/`，C# 不在扫描范围内）。
6. **不存在 GPU 粒子的平台风险**：全仓库零个 `CPUParticles2D` / `GPUParticles2D`，唯一命中是 `chemo_fx.gd:17` 一行解释「为什么不用」的注释。所有「粒子」都是 `_draw()` 手画的纯函数 ⇒ 给定 t 就确定——这正是像素闸成立的前提。
7. **音效成本 ≈ 0**：全游戏只有一声按钮点击（`cw_sfx.gd:19` 的 `CLICK`），文件头明写棋盘上的迁移 / 打牌 / 攻击**不响**（`cw_sfx.gd:1-3`）。
