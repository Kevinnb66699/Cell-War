### 一句话气质

**像一段有旁白的剧**：所有话都从底部那块对白面板里说出来，棋盘上方一件浮层都不放；
提示不是「贴在东西旁边的小泡泡」，而是**一支指向它的箭 + 一圈描边**。玩家的眼睛只在两处来回：
棋盘中央，和屏幕底边。

### 七帧逐帧

#### ① `01_章节提示.png` —— 第一章 Cell

接在开场动画之后。全屏 88% 黑幕，两道细横线夹住「第一章  Cell」（`SIZE_HERO` 40），
下面一行 `CHAPTER I - CELL`（开场页那支 silkscreen + 同一档字距）。幕布背后能看见开场收尾那张全盘。

**为什么这么做**：开场最后一页是「Cell_War / IMMUNE VS. CANCER」，章节提示若换一套字一换气质就断了。
第二、三章同版式，只换字（第二章 Immune / `CHAPTER II - IMMUNE`；第三章 Cancer / `CHAPTER III - CANCER`）。
动效：幕布 0.30s 淡入 → 横线从中间向两端拉开 0.25s → 大字与副标一起淡入 0.25s → 停 1.4s → 整页 0.35s 淡出。
全程禁用操作（通则 9），点击可跳过后半段。

#### ② `02_第一关关首.png` —— 两格健康组织 + 免疫细胞 + 第一句台词 + 【迁移】

剧本第一关：地图是两个横向连接的健康组织，生成未分化免疫细胞在靠左那格，只显示【迁移】按钮。
台词正在说 ⇒ 棋盘罩 12% 黑、【迁移】走 `CWActionBar` 自己的 `disabled`（**位置照占、只变暗**）。
头像是同一只免疫细胞的贴图 ×2，名字「免疫细胞」—— 让玩家第一眼就把「说话的人」和「棋盘上那颗」对上。

两格棋盘在包围盒机位下顶到 zoom 上限 3.2，所以格子和细胞都很大 —— 这是有意的：第一关就该让人看清细胞长什么样。

#### ③ `03_第一关操作中.png` —— 说完了，轮到玩家

台词说完 ⇒ **对白面板收成任务条**，棋盘下缘还回来（可用带从 344 涨到 418），禁用罩撤掉。
【迁移】进提示态：`grow(1)` 2px 青描边 + 左侧一枚箭（**不摆头顶** —— 行动栏钉在 y=476，头顶那 8px 正是任务条下沿）。
目的格用棋盘**原生**的 `MARK_MOVE` 剪影 + 上方一枚箭，不另画一套高亮：那是玩家进正式局后天天见的那个颜色，教程里就该是同一个。

任务条左端一枚小箭 + 一行任务（「使用【迁移】，向前行动一格」），右端是常驻的重置 / 目录。

#### ④ `04_第三关右栏与图鉴.png` —— 右栏弹出 + 癌组织连通块 + 两条图鉴横幅

剧本第三关：地图向前方延伸、几格外一个**凸的**癌组织连通块、右侧边栏弹出（状态框 + 抗原记忆框）。
对白面板右缘收到 688 给右栏让位，文字列从 800px 缩到 540px。

横幅这里**故意摆两条**（一关里连着解锁好几条是剧本常态，第一关就是【健康组织】+【迁移】），
为的是看两条叠起来会不会顶到棋盘 —— 会压住左下角两格，见下面风险 5。第三关真实只解锁【攻击】一条。

右栏走的是**真 `CWMatchPanel`**，`guide_layers(end_turn=false, round_no=false)`。
关掉回合块的理由见风险 2。

#### ⑤ `05_目录面板.png` —— 目录

从底部那条的「目录」页签拉开（页签本身进 `link_hot` 白光态），对白面板留在底下不动 ——
玩家看得见自己是从哪一关点开的。两栏：左边第一 / 第二章，右边间章 / 第三 / 第四章。
第四章「敬请期待」用 `TEXT_OFF_DIM`，读成「有这么个东西，但还没有」。

动效：面板从对白面板上沿向上展开 0.22s（纵向缩放 + 淡入），背景 55% 黑同步淡入。

#### ⑥ `06_第七关结束回合.png` —— 全屏级引导 + 按钮旁文字提示 + 上方无回合数

剧本第七关：玩家控制癌细胞，右栏只显示玩家癌细胞与其余免疫的状态 + 免疫等级、**上方不显示第 X 回合**、
显示结束回合按钮、其他 UI 隐藏。提示色整关跟着当前控制方 ⇒ **全是癌方橙**。

- 全屏 45% 黑，只给【结束回合】挖一个洞（`Rect2(712, 472, 232, 52)`，= `CWMatchPanel` 的 PAD/W/END_H 算出来的）；
- 洞外一圈 2px 橙描边 + 上方、左侧各一枚橙箭收拢（**下方与右方不放** —— 按钮钉在右下角，下沿离屏底只有 16）；
- 按钮左边挂文字提示条「点击结算【微环境压迫】」，尖角指向按钮；
- 任务条同时在，写「点击【结束回合】」。

**任务条和控件提示条分工是故意的**：任务条说**做什么**，控件提示条说**会发生什么**。
第七关后半的「技能按钮弹出文字提示：使用【转移】接近T细胞 / 使用【粘液破裂】」走同一条提示条，只是挂在行动栏的技能按钮上。

#### ⑦ `07_自动重置提示.png` —— 通则 7（选做帧）

画的是动画**中段**：棋盘整体淡到 45%，四向箭头朝中央收拢，中间一块牌写明为什么重来
（「自动重置 · 回到本关起点」+ 小字「能量不足以抵达癌细胞」）。
口径：棋盘淡出 0.35s → 摆回本关初始状态 → 淡入 0.35s，全程禁用操作，牌在中段 0.6s 内可见。
**必须说清为什么**：剧本第三关的自动重置条件是「能量不足 / 剩余能量小于预期」，玩家自己看不出来。

**地图延伸的浮现动画**（通则 6）本稿没单出帧，口径写在这里：沿用棋盘现成的
`set_active_tiles(tiles, 0.45)` —— 新进集合的格按同心圆由内向外错峰淡入（`ACTIVE_RING_DELAY`），
和开场癌组织绽开是同一个语汇。相机 zoom 同步补 0.45s 到新包围盒对应的档。

### 风险与待拍板

1. **右栏在教程前期会泄题。** 第三关右栏一弹出来，「癌性加权 0 / 90」「肿瘤 I 期」「技 0」「+4.5 预计收入」
   「手牌方块」全都在，而这些到第四章才讲。`CWMatchPanel` 现在只有 `end_turn` / `round_no` 两道教程闸，
   **要再加一道**（胜负进度块 + 玩家行的细节），否则第三关右栏是「一下子把整个 HUD 砸给玩家」。
   出图里我原样保留了，就是想让这一条看得见。

2. **回合数应该整整三章都关掉，不只第七关。** 剧本把「回合」放在第四章 Game（「跟回合有关的」），
   所以第一 ~ 三章右栏都该 `round_no=false`。本稿七帧全按 false 出。请 Kevin 确认这条推断。

3. **第一、二关没有右栏时，【迁移】孤零零偏在右下。** `CWActionBar.BAR_RECT` 是按正式局的棋盘右缘 685
   右对齐的；教程没有右栏时画面重心在正中，按钮却还贴在 685（见 ②③ 帧）。两条路：给行动栏加一档
   「无右栏时居中」，或者方向 B 干脆把「只有一个按钮」的关卡的按钮摆到任务条右端。我倾向前者（少一套件）。

4. **第七关玩家自己的细胞几乎看不见。** 小细胞肺癌只有 16×18（美术故意画小的，不许拿缩放去凑），
   站在固化癌组织那块暗红上时，在 ⑥ 帧里几乎读不出来。建议给「当前控制角色」挂常驻回合脚标
   （`CWBoard.set_turn_mark` 现成，方案 D 那枚头顶箭），代价很小。

5. **图鉴横幅会压棋盘。** 横幅左缘对齐台词列（x=124），第三关会压住棋盘左下角两格（④ 帧）。
   同屏两条是上限，第三条排队等前一条淡出。若 Kevin 嫌压，备选是把横幅改成**右对齐到对白面板右缘**
   （那一侧在有右栏的关里是空的），代价是它离台词列远了、不那么像「同一个人顺口说的」。

6. **字数上限。** 文字列全宽 800px = 40 汉字/行，右栏在时 540px = 27 汉字/行；面板 108 高只容两行
