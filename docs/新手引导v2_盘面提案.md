## 0. 通用口径（改哪一关都绕不过）

1. **坐标是轴坐标 `(q,r)`** —— 图上每个活跃格中央下方那行小字就是它。六个方向 = `(+1,0) (+1,-1) (0,-1) (-1,0) (-1,+1) (0,+1)`；两格距离 = `(|dq| + |dr| + |dq+dr|) / 2`。**`r` 是横排、`+q` 向右。**
2. **棋盘半径全程 6、127 格恒在**。教程的小棋盘是**遮罩**（一个活跃格集合），不是重铺格网。关内要把地图「延伸开来」，就是往活跃集里加坐标（`reveal`），**零重装**。图上看不见的格子仍然真实存在，只是 `hex_at` 只扫活跃集 ⇒ 看不见也点不到。
3. **（v2 新增，最硬的一条）活跃集只增不减、逐关严格超集**。全教程一共露出 **58 格**，分七次长出来：2 → 7 → 26 → 38 → 47 → 55 → 58。出图脚本每次跑都核一遍「超集缺口」，缺口必须是 0。**已露出的格子不许改坐标**，只许改它上面的组织类型与细胞。
4. **11 个特殊组织格**：代谢核心 `(0,-3) (3,0) (-3,3)`；骨髓 `(3,-3) (0,3) (-3,0) (6,-3) (-3,-3) (-3,6)`；血管 `(6,0) (-6,0)`。它们的 `r` 只取 -3 / 0 / 3 / 6 ⇒ **`r = -1 / -2 / -4 / -5 / 1 / 2` 六整排一个特殊格都没有**，所以教学走廊走 `r=-1`、横带往 `r=-2` 与 `r=0` 长。全教程只压到 **5 格**特殊格，逐格显式写 `"type": "normal"` 摊平（否则白送玩家一个收入格）：`(3,0)` `(6,0)`（第三关）、`(3,-3)`（第四关）、`(-3,0)` `(6,-3)`（第七关）。
5. **能量一律十分位整数**（`30` = 3.0）。`∞` = 哨兵 `99990` + UI 层 `energy:"infinite"`；`Null` = 同一个哨兵 + `energy:"null"` + 旋钮 `overload_div: 0`。「本关【迁移】不消耗能量」落不到旋钮（`immune_move_*` 是 tier C），只能靠大能量 + `cost:false` + `move_path:false` 盖住。
6. **一格一细胞、一席一细胞**。PRD 里的「若干癌细胞」要逐只展开成席位。**右栏 9 席到顶**：让掉回合块那 62px 之后，9 席的底边 532 ≤ 540，10 席放不下。**这是席位预算，不是地图预算** —— 只有第五关顶到 9 席。
7. **镜头**：机位按活跃集推近（`board.set_active_tiles` + 包围盒）。第一关 3.2 倍（顶格），到第七关掉到 ~1.4 倍 —— 教程从贴脸开始、一路拉开到接近正式对局的视野，这是地图连续生长换来的免费收益。
8. **图上的颜色**：绿 = 健康组织，红 = 癌组织，石 = 固化癌组织，灰纹 = 坏死；坐标写成青色 = 这格站着免疫细胞，写成橙色 = 站着癌细胞；**淡青剪影 = 本关新浮现的格**，**橙色剪影 = 要 hxr 圈的癌组织 / 固化格**，**深青剪影 = 几何锚点**。

## 六、间章 癌变（PRD:385-411）—— 怎么接到第七关

- 代价：只搬**一只**细胞。此后全部确定：
  - 分镜 8/9（PRD:407-409「附近最近一个免疫细胞移动到癌细胞附近，攻击癌细胞三次」）——最近的是巨噬 `(5,0)`，钩子让它走到 **`(5,-2)`** 打三下；

### 方案乙：全程原地，到分镜 10 才摆

- 分镜 1~9 全在玩家第五关最后站的那一格演，分镜 10 那次重装（冲击波 + 固化 + 击退）把玩家**连同刚才攻击它的那只免疫**一起摆到 `(6,-2)` / `(4,-2)`。

### 7.4 几何核算（v2 重算，一条都不能动）

> 全部挂在 **`r=-1` 排**上 —— 那是第一～三关一路走过来的走廊，`q` 从 -5 到 6 共 12 格、跨度 **11**，一个特殊格都没有。**第七关的几何不是新画的，是前三关走出来的。**

1. 【转移】固定跃进 **5 格**（`METASTASIS_RANGE := 5`，`cw_data.gd:341`）⇒ 转移那一刻玩家到 T 的距离必须是 **`5k + 1`**；`5k` 会正好落到 T 细胞头上 = 非法。
2. PRD:467-473（第 10~13 步）是「前进 1 → 击退 2」**两轮**，每轮净 **+1** ⇒ 击退序列开始时的距离 `D` 必须满足 `D + 2 = 5k + 1`。**取 D = 9**。
3. `D = 9` ⇒ **围完一圈停 `(4,-1)`、T 站 `(-5,-1)`**。两格同在 `r=-1` 排：既零特殊格，又天然是一条直线，正好落 PRD:461。
   > 「一条直线」是**规则要求，不只是演出**：T 的【效应应答-Excalibur】是「选定六个方向中的一个，主射线以 T 所在格为起点向该方向延伸至棋盘边缘」（`cw_data.gd:810`）。不在同一条射线上，这一发就打不到。
4. 两轮之后：`(4,-1)` →（进 1）`(3,-1)` →（退 2）`(5,-1)` →（进 1）`(4,-1)` →（退 2）**`(6,-1)`**，距离 **11 = 5×2+1** ⇒ 两次【转移】沿 `(-1,0)`：`(6,-1)` → `(1,-1)` → **`(-4,-1)`**，与 T 正好邻接。
