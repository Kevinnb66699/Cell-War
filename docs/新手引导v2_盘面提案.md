## 0. 通用口径（改哪一关都绕不过）

1. **坐标是轴坐标 `(q,r)`** —— 图上每个格中央下方那行小字就是它。六个方向 = `(+1,0) (+1,-1) (0,-1) (-1,0) (-1,+1) (0,+1)`；两格距离 = `(|dq| + |dr| + |dq+dr|) / 2`。**`r` 是横排、`+q` 向右。**
2. **棋盘半径 6、127 格恒在**。教程的小棋盘是**遮罩**（一个活跃格集合），不是重铺格网。「地图延伸」= 往活跃集里加坐标（`reveal`），**零重装**。看不见的格子仍然真实存在，只是 `hex_at` 只扫活跃集 ⇒ 看不见也点不到。
3. **活跃集只增不减、逐关严格超集**：2 → 7 → 37 → **127**（第四关）→ 127 → 127 → 127。**已露出的格子不许改坐标**，只许改它上面的组织类型与细胞。
4. **第四关起就是正常棋盘**：11 格特殊组织（代谢核心 `(0,-3) (3,0) (-3,3)`、骨髓 `(3,-3) (0,3) (-3,0) (6,-3) (-3,-3) (-3,6)`、血管 `(6,0) (-6,0)`）按本来的样子显示，不摊平（理由见上）。
5. **能量一律十分位整数**（`30` = 3.0）。`∞` = 哨兵 `99990` + UI 层 `energy:"infinite"`；`Null` = 同一个哨兵 + `energy:"null"` + 旋钮 `overload_div: 0`。「本关【迁移】不消耗能量」落不到旋钮（`immune_move_*` 是 tier C），只能靠大能量 + `cost:false` + `move_path:false` 盖住。
6. **一格一细胞、一席一细胞**。PRD 的「若干癌细胞」逐只展开成席位。**右栏 9 席到顶**（9 席底边 532 ≤ 540，10 席放不下）。**这是席位预算，不是地图预算。**
7. **同阵营两两至少隔 2 格**（Kevin ④），尽量 3 格以上；癌组织连通块之间至少隔 3 格。
8. **镜头**：机位按活跃集推近。第一关 3.2 倍（顶格），第四关起整盘约 1.0 倍 —— 教程从贴脸开始、第四关一把拉到正式对局的视野。
9. **图上的颜色**：绿 = 健康组织，红 = 癌组织，石 = 固化癌组织，灰纹 = 坏死；坐标青 = 这格站着免疫，橙 = 站着癌细胞；**淡青剪影 = 本关新浮现的格**，**橙剪影 = 要 hxr 圈的癌组织 / 固化格 / 再生格**，**深青剪影 = 几何锚点**。

### 7.4 几何核算（在整盘上重算过，结论与 v2 一致）

> 全部挂在 **`r=-1` 排**上 —— 那是第一～三关一路走过来的走廊，`q` 从 -5 到 6 共 12 格、跨度 **11**。**第七关的几何不是新画的，是前三关走出来的。** 整盘揭开不影响它：`r=-1` 排的两端 `(-5,-1)` 与 `(6,-1)` 本来就是棋盘边界（`s=6` / `q=6`）。

1. 【转移】固定跃进 **5 格**（`METASTASIS_RANGE := 5`，`cw_data.gd:341`）⇒ 转移那一刻到 T 的距离必须是 **`5k + 1`**；`5k` 会正好落到 T 头上 = 非法。
2. PRD:467-473 是「前进 1 → 击退 2」**两轮**，每轮净 **+1** ⇒ 击退序列开始时的距离 `D` 必须满足 `D + 2 = 5k + 1`。**取 D = 9**。
3. `D = 9` ⇒ **围完一圈停 `(4,-1)`、T 站 `(-5,-1)`**。同在 `r=-1` 排，天然一条直线，正好落 PRD:461。
   > 「一条直线」是**规则要求，不只是演出**：T 的【效应应答-Excalibur】是「选定六个方向中的一个，主射线以 T 所在格为起点向该方向延伸至棋盘边缘」（`cw_data.gd:810`）。不在同一条射线上，这一发打不到。
4. 两轮：`(4,-1)` →（进 1）`(3,-1)` →（退 2）`(5,-1)` →（进 1）`(4,-1)` →（退 2）**`(6,-1)`**，距离 **11 = 5×2+1** ⇒ 两次【转移】沿 `(-1,0)`：`(6,-1)` → `(1,-1)` → **`(-4,-1)`**，与 T 正好邻接。
5. **击退朝右、终点顶死在 `q=6`**：`(6,-1)` 是 `r=-1` 排的最右端，再退一格就出盘 —— 两轮击退用满这条线，**一格不多一格不少**。整盘揭开后这条边界没变（`q=6` 就是棋盘外环）。
6. **玩家开局 `(6,-2)`，不是 `(4,-1)`。** 从 `(6,-2)` 起 6 步把 `(4,-2)` 的一环踩满并停在 `(4,-1)`。而 `(6,-2)` 与 `(4,-2)` 距离恰好 **2 且在一条直线上**（方向 `(-1,0)`）—— 这**不是凑的**，正是间章分镜 10「将一环内免疫细胞向外击退 1 格」的结果（巨噬从邻接的 `(5,-2)` 被推到 `(4,-2)`）。**间章的最后一拍就是第七关的开局摆拍。**
7. **死亡窗口内，盘上至少要有一格 `state:"solid"` 且不被免疫占据。** 自毁到下一个 S 阶段复活之间隔着一次 E，那一刻 `living_cells(CANCER)` 为空、第一道胜负闸过不住，只剩固化格兜底 —— Kevin 09-12 截图报过的「教程过完直接弹结算」就是这条路径。盘上有 **4 格**固化（`(6,-2)` `(6,-1)` `(1,-5)` `(2,3)`），全在免疫够不着的地方。
8. **围出来的那一环不许有固化格**：`(4,-2)` 的六邻一格固化都没有（第五关那三格特意避开），玩家要靠自己 6 步把六格全踩成癌组织，【微环境压迫】才是他亲手算出来的结果。
9. **必写 `overload_div: 0`**（第七关真跑 E 阶段，【能量过载】会把 99990 每回合啃掉 15.0 并写进左侧出牌列）；`cancer_win_hold_rounds: 99` 挡掉癌方加权胜利；世界回合 ≤ 5 保住癌 I 期。
10. **T 细胞第七关全程不动**（钩子给它空 `plan`）。PRD:453 的「所有免疫细胞向靠近癌细胞的方向移动一格」对它开口子 —— PRD:461 本来就写着「T 细胞位置应**合理设计满足后续演出需求**」。会动的是 B 与树突。
11. **第 8 步的轮数与路线由钩子 `repeat_until_last_t` 控制，唯一的硬约束：最后一轮结束时玩家站 `(4,-1)`。**
12. **整盘揭开后，增生 / 侵蚀 / 微环境压迫全都看得见了**（v2 时它们在遮罩外偷偷发生）。处置不变（增生拧 0、侵蚀这盘打不到、压迫真结算），但实装时要真机看一眼左侧出牌列有没有一堆看不懂的行。
