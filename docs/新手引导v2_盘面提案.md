## 0. 通用口径（改哪一关都绕不过）

1. **坐标是轴坐标 `(q,r)`** —— 图上每个活跃格中央下方那行小字就是它。六个方向 = `(+1,0) (+1,-1) (0,-1) (-1,0) (-1,+1) (0,+1)`；两格距离 = `(|dq| + |dr| + |dq+dr|) / 2`。
2. **棋盘半径全程 6、127 格恒在**。教程的小棋盘是**遮罩**（一个活跃格集合），不是重铺格网。关内要把地图「延伸开来」，就是往活跃集里加坐标（`reveal`），**零重装**。图上淡到看不见的格子仍然真实存在，只是 `hex_at` 只扫活跃集 ⇒ 看不见也点不到。
3. **11 个特殊组织格**：代谢核心 `(0,-3) (3,0) (-3,3)`；骨髓 `(3,-3) (0,3) (-3,0) (6,-3) (-3,-3) (-3,6)`；血管 `(6,0) (-6,0)`。它们的 `r` 只取 -3 / 0 / 3 / 6 ⇒ **`r=-1` 与 `r=-2` 两整排一个特殊格都没有**，所以第一～三章的教学带和第七关的直线走廊都走这两排。压到这 11 格的活跃格要逐格显式写 `"type": "normal"`，否则白送玩家一个收入格。
4. **能量一律十分位整数**（`30` = 3.0）。`∞` = 哨兵 `99990` + UI 层 `energy:"infinite"`；`Null` = 同一个哨兵 + `energy:"null"` + 旋钮 `overload_div: 0`。「本关【迁移】不消耗能量」落不到旋钮（`immune_move_*` 是 tier C），只能靠大能量 + `cost:false` + `move_path:false` 盖住。
5. **一格一细胞、一席一细胞**。PRD 里的「若干癌细胞」要逐只展开成席位。**右栏 9 席到顶**：让掉回合块那 62px 之后，9 席的底边 532 ≤ 540，10 席放不下。所以每一关的细胞只数是硬预算。
6. **图上的颜色**：绿 = 健康组织，红 = 癌组织，石 = 固化癌组织，灰纹 = 坏死；坐标写成青色 = 这格站着免疫细胞，写成橙色 = 站着癌细胞；橙色剪影 = 要 hxr 确认的格，青色剪影 = 几何锚点。

1. 【转移】固定跃进 **5 格** ⇒ 转移那一刻玩家到 T 的距离必须是 **`5k + 1`**；`5k` 会正好落到 T 细胞头上 = 非法。

3. `D = 9` ⇒ 玩家 `(-3,-1)`、T `(6,-1)`。两格同在 `r=-1` 排：既零特殊格，又天然是一条直线，正好落 PRD:461。
4. 两轮之后玩家落 `(-5,-1)`、距离 **11 = 5×2+1** ⇒ 两次【转移】`(-5,-1)` → `(0,-1)` → `(5,-1)`，`(5,-1)` 正好与 T 邻接。
5. **起点不能取 `(-5,-1)`**：第一次击退要落到 `(-6,-1)`，`q+r = -7` 已出盘，装载器当场拒。
6. **方案里写的「玩家 `(-3,-1)`」是围完一圈之后的位置，不是开局位置。** 开局必须放 `(-3,-2)` —— 以 `(-4,-1)` 为心的一环，从 `(-3,-2)` 起走 5 步正好把环走完**并停在 `(-3,-1)`**。若开局直接放 `(-3,-1)`，5 步之后会停在 `(-4,0)`，到 T 的距离是 10，后面整套几何当场散架。
7. **死亡窗口内，盘上至少要有一格 `state:"solid"` 且不被免疫占据。** 自毁到下一个 S 阶段复活之间隔着一次 E，那一刻 `living_cells(CANCER)` 为空、第一道胜负闸过不住，只剩固化格兜底 —— Kevin 09-12 截图报过的「教程过完直接弹结算」就是这条路径。默认那一格就是 `(-3,-2)`。
