## 0. 通用口径

1. **轴坐标 `(q,r)`**，`r` 是横排、`+q` 向右；距离 = `(|dq| + |dr| + |dq+dr|) / 2`。
2. **棋盘半径 6、127 格恒在**；教程的小棋盘是**遮罩**，不是重铺格网。「地图延伸」= 往活跃集里加坐标（`reveal`），零重装。
3. **活跃集只增不减、逐关严格超集**：2 → 7 → 37 → **127**（第四关一次揭完）→ 127 → 127 → 127。**已露出的格子不许改坐标。**
4. **第四关起就是正常棋盘**：11 格特殊组织按本来的样子，**不摊平**（第一～五关从 `PlayerAction` 中途开局、闸里永不放「结束回合」⇒ 进不到 S 阶段 ⇒ 收入与存卡不结算，摊不摊平零影响）。
5. **能量十分位整数**（`30` = 3.0）。`∞` = 哨兵 `99990` + `energy:"infinite"`；`Null` = 同哨兵 + `energy:"null"` + `overload_div: 0`。「迁移不消耗能量」落不到旋钮（`immune_move_*` 是 tier C），只能大能量 + `cost:false` + `move_path:false`。
6. **一格一细胞、一席一细胞**；**右栏 9 席到顶**（席位预算，不是地图预算）。
7. **同阵营细胞两两至少隔 2 格**（尽量 3 格以上）；**癌组织连通块两两至少隔 3 格**。
8. **镜头**按活跃集推近：第一关 3.2 倍，第四关起整盘约 1.0 倍。
9. **图上的颜色**：绿 = 健康，红 = 癌组织，石 = 固化，灰纹 = 坏死；坐标青 = 站着免疫、橙 = 站着癌细胞；**淡青剪影 = 本关新浮现的格**，**橙剪影 = 要圈的癌组织 / 固化 / 再生格**，**深青剪影 = 几何锚点**。

### 能量账重算（v4 的核心改动）

癌细胞 `(5,-1)` 的一环 = `(6,-1)` `(6,-2)` `(5,-2)` `(4,-1)` `(4,0)` `(5,0)`。加上 `(3,0)(4,0)(5,0)` 之后，**一环里只剩 `(6,-2)` 一格健康，而它四周全被癌组织包着、只能穿过癌组织到达**。逐格 Dijkstra（健康 0.5 / 癌 1.0）：

| 落点 | 最省走法 | 花费 |
|---|---|---|
| **`(4,-1)`** | 直线：`(1,-1)` `(2,-1)` 健康 + `(3,-1)` `(4,-1)` 癌 | **3.0** |
| **`(5,-2)`** | 绕 `r=-2` 排：`(1,-2)` `(2,-2)` `(3,-2)` `(4,-2)` 健康 + `(5,-2)` 癌 | **3.0** |
| `(4,0)` | 绕 `r=0` 排：`(0,0)` `(1,0)` `(2,0)` 健康 + `(3,0)` `(4,0)` 癌 | 3.5 |
| `(6,-2)` | 走到 `(5,-2)` 再进 `(6,-2)` | 3.5 |
| `(5,0)` / `(6,-1)` | —— | 4.5 |

- **最省 = 3.0，两条并列**（图上两个深青落点）。
- **能量 `6.6`** = 3.0（最省路）+ 3.0（攻击三次 × 1.0）+ 0.5（失效自损 `COUNTER_DMG_ON_FAIL := 5`）+ 0.1（PRD:243）。
- **劝重置阈值仍是 35**（十分能量 = 攻击三次 30 + 反弹 5）：走 3.0 剩 **36** ≥ 35 不劝；次优 3.5 剩 **31** < 35 当场劝。阈值把 30 和 35 分得干干净净，不用动。
- 伤害 1.0 + 0 + 2.0 = 3.0，第三次刚好打死；`ATTACK_MAX_PER_TURN = 3` 锁死带子长度。
- 自动重置只有「能量不足以移动」一条；「所剩能量小于预期」按 Kevin 09-19 是**劝重置**不自动重置。

- **Q3-2** 外突连通块 9 格的形状（中排 4 + 柄 2 + 下排 3）。
