## ⚠ 与「昨天凌晨测试时用的值」的差异（两个字段）

团队要的是「昨天凌晨（g7 / g7b / g8 / g8b 四局 Sonnet 对弈）跑的那套值」。
那之后我按团队拍板落地了抗体改动，所以**此刻的默认值与那时有两处不同**：

| 字段 | 昨天凌晨 | 此刻 | 说明 |
|---|---|---|---|
| `antibody_halve` | **不存在**（= 每次都打满） | `true` | 【抗体】同回合递减 1.5/0.7/0.3/0.1/0，团队 09-04 拍板，PRD 已改 |
| `anaerobic_sqrt_coef` | **不存在** | `0` | 开方刹车候选旋钮，**0 = 关，行为与昨天完全一致** |

也就是说：**只有抗体那一条是真的行为差异**，其余 42 个字段与昨天凌晨逐字相同。
要精确复现昨天那四局，在命令行加 `abhalf=0` 即可。

## 与本次改动直接相关的几项（团队新方案要动的）

| 字段 | 当前值 | 含义 |
|---|---|---|
| `energy_cap` | `150` | **能量上限 15.0** —— 新方案要取消的就是它 |
| `anaerobic_cap` | `9990` | 无氧呼吸每回合进账上限 999.0（形同不封顶） |
| `aerobic_cap` | `0` | 有氧呼吸进账上限，0 = 不封顶 |
| `aerobic_mult` | `30` | 有氧系数，公式里的「×3」 |
| `aerobic_floor` | `20` | 有氧下限 2.0（口径 #89） |
| `aerobic_mult_growth` | `0` | 有氧系数每回合再涨多少（候选①，关着） |

| `anaerobic_per_cancer` | `4` | 每格癌组织供能 0.4 —— **新方案说不动无氧，这项保持** |
| `anaerobic_per_solid` | `10` | 每格固化癌组织供能 1.0 —— 同上，保持 |

## 相关常量出处

以上默认值多数取自 `game/scripts/core/cw_data.gd` 的常量，
少数直接写在 `game/scripts/core/cw_tuning.gd`。改默认值要改的是**常量那一处**，
不是在 `CWTuning` 里另写一个数 —— 两处各写一份就会分叉。
