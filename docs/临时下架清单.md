## 三条共同的纪律

1. **只关「界面上有没有入口」，一点底层都不动。** 类还在、协议一个字没改、
   服务器那半边照常收发、回放照常录照常存盘。所以开回来那天：
   **不用补数据、不用改协议、不用重新部署服务器。**
2. **护栏测试照常跑。** 每个功能自己那几条测试（`t_chat_box` / `t_replay` /
   `t_replay_panel` / `t_net_chat` / `t_net_replay_download`）
   一条都没删 —— 开回来那天不用从头验一遍。
   而跟「入口在不在」有关的断言都写成了 `== CWMatch.XXX_ON`，
   **改开关不用改测试**，套件自己跟着走。
3. **改这三行要连着改这份文档。** 否则下一个人只能靠 grep 猜。
