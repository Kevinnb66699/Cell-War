# 架构审查台账（2026-09-02）

基线：`origin/main` / `23d71ebb365b0252893d380b8a82792885528924`。

## 已核对的依赖链

```text
UI（CWMatch / CWUIBridge）和 AI（启发式 / Monte Carlo）
  → CWBridge（ask / show_roll / show_result）
  → CWGame（状态、pending/step/advance、快照、销毁）
  → CWSetup / CWWorld / CWTurn / CWActions / CWCards
  → CWCost / CWDamage / 组织格字典
```

`CWGame` 创建流程模块并注入 `module.game`（`cw_game.gd:init`）；模块反向持有
`CWGame`，因此拆局必须调用 `dispose()` 清除模块与桥的反向引用（`cw_game.gd:327`）。
MC 推演临时替换 `game.bridges`，结束时还原并清空陪练的 `game`（`monte_carlo_bridge.gd:_mc_pick`）。

- Ryzen 9 7945HX：固定种子早/中/晚局面，无限预算各 656 步、187.5/194.2/195.2 ms；192 步各 51.5/52.7/58.8 ms。浅层 MC（r=1/h=2/budget=24）2/4/6 人分别 3.17/2.43/2.85 s，均正常结束。
