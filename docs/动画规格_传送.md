## 一、适用场景（哪些传送要演）

规则里所有"位置非连续变化"都算传送，共用同一套演出：

| 场景 | 引擎入口 | 特殊处理 |
|---|---|---|
| 血管传送（S 阶段，两端互换） | `CWWorld._vessel_teleport` | 演出前血管格先亮 0.1s 交代"是血管干的"；两端完全同时演，暗示互换 |
| 世界事件【紊乱】（全场齐传 + 回合末返回） | `CWWorldFx` | 按**离事件波及重心的环数错峰**（复用 `board.ring_delays()`，每环 ~0.045s），全场波浪式沉/冒 |
| 卡牌位移（免疫增援 / 肿瘤细胞募集等） | `CWCardFx` | 标准两段式；目的地随机，"冒头悬念"本身就是演出 |
| 复活落位 | `CWActions.enter_tile` | **不演传送**，维持现有 `_pop_in` 淡入即可 |

## 二、效果形态（最终定稿）

一句话：**向下偏置的像素溶解离场 → 延迟后同 shader 倒放凝出落场，溶解边缘泛色，白闪落点；全程没有任何位移。**

### 两段式时序（单细胞）

```
t=0        离场开始：原格残影溶解（progress 0→1，0.25s）
           溶解从脚底开始向上蔓延（头顶最后消失）
           溶解边缘带 1~2px 阵营色亮边：免疫青 #30D1FA / 癌方橙 #FFB03A
t=0.15     落场开始：真身在新格凝出（progress 1→0，0.30s）
           凝出从脚底开始向上长回（脚底先破土）
           边缘亮边换成白色；同时 scale 做 0.6→1.10→1.0 的过冲（弹性落地感）
           落地完成瞬间目标格白闪一下（复用开场翻面的 _flash）
t=0.45     全部结束
```

要点：

- **两段重叠 0.15s**——"那个消失的和这个出现的是同一个"靠这层重叠读出来，别做成串行。
- **不移动一个像素的位移**。CWMatch 每帧用引擎状态覆写细胞节点的 `position` / `z_index`，位移不可碰；shader 效果全部发生在精灵 UV 空间，天然合规。`scale` 过冲只在凝出阶段短暂驱动，凝出结束时必须回到 `Vector2.ONE`，否则会被下一帧 `_sync_cells` 覆写出一帧抖动。

### shader 参数速查（`assets/shaders/teleport.gdshader`）

| uniform | 用法 |
|---|---|
| `progress` | 0=完好 1=全溶解。离场补间 0→1，落场补间 1→0 |
| `emerge` | 方向开关：0=沉入（可见区从顶部收缩），1=凝出（可见区从脚底扩张）。**凝出开始时必须先置 1 再倒放 progress**，直接倒放会从头顶冒出来（踩过的坑） |
| `edge_color` | 离场喂阵营色，凝出置白，凝出结束改回阵营色备用 |
| `sink_bias` | 1.0，别动；`noise_spread` 0.35、`edge_width` 0.10 同理——三者的相对量级是调出来的，动了任何一个都可能退化成"原地同时碎掉"（开发日志有记录） |

材质注意：**material 必须逐实例 `duplicate()`**，不能像 silhouette 那样共用一份（progress 是逐细胞的）。

## 三、接入方案（程序侧实现指导）

### 1. 检测：状态差分，不走信号

在 `CWMatch._sync_cells()` 里给每个细胞记上一帧位置（`_last_pos[i]`）。当帧发现：

- 该细胞上一帧和这一帧都存活，且
- 新旧两格**不相邻**（六邻域判断，用 `CWData` 的轴坐标距离，别用像素距离）

→ 判定为传送，触发一次演出。这与 CWMatch"每帧全量刷新、从状态推演出"的哲学一致：引擎零改动、不需要新信号，联机影子对局（服务器快照 restore 后逐帧同步）下天然工作。**不要**往 `cw_world` / `cw_actions` 里加演出回调。

复活（`paid == -1` 且原来是死）已被 `_was_alive` 差分覆盖，继续走 `_pop_in`，别和传送混淆——判定顺序：先查复活，再查传送。

### 2. 演出：残影节点 + 真身

离场演出期间，真身已经在新位置被 `_sync_cells` 正常画出来了。溶解的是**残影**：

1. 建临时 `Sprite2D`（`_marks` 同层），复制离场细胞那一帧：同贴图、同 `hframes=6`、同 `offset`、同 frame 号，`position`/`z_index` 用旧格的 `tile_center()` / `tile_z(旧格, Z_CELL)`（这两样不受每帧覆写影响，直接算一次即可）。
2. 挂 duplicate 的 teleport material，驱动 `progress` 0→1，0.25s 后 `queue_free()`。
3. 真身侧：置 `emerge=1`、`edge_color=白`，progress 1→0（0.3s）+ scale 过冲 + 目标格白闪（往 `_flash` 塞目标格即可，现成的）。
4. 呼吸帧号继续按全局 `_breath_step` 推——残影和真身都要跟，否则帧率不一致穿帮。

### 3. 批量：错峰与句柄管理

- **紊乱**这类全场齐传：同一帧可能检出十几个传送。按 `board.ring_delays(受影响格, 0.045)` 给每个演出加启动延迟，波浪式推进。**错峰的是演出开始时刻，检测本身每帧照常做**。
- 残影补间的句柄必须收进一个 `_teleport_tweens: Array[Tween]`，teardown()（以及开局 reset）时**先 `kill()` 再删节点**——仓库里 `_fade_tweens` / `_fade_overs` 的注释记录过血泪教训：queue_free 是帧末删除，补间会活过拆局跑进下一局。
- 残影节点挂棋盘层，不进 `_cell_nodes`（那数组下标 = cell id，不许污染）。

### 4. 开关与降级

- 设置页加一项"传送演出"（对齐"掷骰动画"先例，`CWSettings` + `settings_page`）：关掉时检测照做、演出全跳（细胞照旧瞬移）。AI 互搏观战局紊乱频繁，需要这个降噪开关。
- 演出期间**不阻塞任何结算**——shader 是纯视觉，引擎不会等它。若未来要做"演出完再结算"，另立议题。

### 5. 验收清单

- [x] 血管互换：两端同时沉、同时冒，血管格先亮（两端同帧检出、同一 0.1s 延迟；`t_teleport_fx`）
- [x] 紊乱：波浪式错峰（`board.ring_delays` 每环 0.045s），回合末返回是又一次位置跳变、同样检出
- [x] 增援/募集：单细胞标准两段式（任何不相邻的位置跳变都走同一条路，呈现层不问是谁干的）
- [x] 复活仍是淡入，不是溶解（先查 `_was_alive` 再查传送；`t_teleport_fx`）
- [x] 同格多细胞错开（STACK_DX 偏移）的任一个被传送时，残影位置与它原站位一致（残影抄的是节点被覆写前的上一帧实际 position；`t_teleport_fx`）
- [x] 演出中存档/读档/退出到主菜单：无残留补间、无幽灵残影（`teardown()` 先 `clear_all()` 杀补间再删节点；`t_teleport_fx` 拆局段）
- [x] 联机模式影子对局里同样触发（同一条 `_sync_cells`、不依赖引擎信号 —— 代码同路径的推论，尚未在公网真机上肉眼验过）
- [x] 关闭开关后行为与现在完全一致（`CWSettings.teleport_anim=false`：检测照做、`_play_teleports` 直接返回；`t_teleport_fx`）
