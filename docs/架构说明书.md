# Cell War 新版 · 架构说明书

> 本文档是项目结构的唯一权威说明，供 AI 与人类协作者快速接手。
> **铁律：架构层面的任何变化（新模块、目录调整、关键流程改动）必须在同一次提交里同步本文档。**

## 项目是什么

《Cell War》桌游（免疫细胞 vs 癌细胞，ver.0.98 规则）的电子化新版工程。

旧版 demo（Godot 4，完整规则引擎 + 热座 + 人机对战 + CI）在
https://github.com/Kevinnb66699/SpringSense-2026-2027-Cell-War ，可作规则与实现参考。

## 当前状态

2026-08-26：仓库初始化。**游戏规则已修改，新版从零重建，不继承旧版代码**；引擎沿用 Godot 4（GDScript，本机 Godot 4.5 stable）。等待新版规则文档到位后开始搭建引擎。
