## 〇、口径与完工定义

### 0.1 一句话

把 GD 无头测试里的 **core 规则断言**变成两侧共读的一份 JSON，
**但只有 PRD 里本来就有名字、或本来就有步号的步才配拥有 op 名**；
产出方式以**跑一遍原测试、由录制代理收割**为主，手翻只留录不到的零散条目。

### 0.2 完工定义

| 层级 | 完工条件 |
|---|---|
| 单条用例 | 同一份 JSON，**GD runner 与 C# runner 都绿**，且它的 `covers` 指得到 `game/tests/headless_test.gd` 里一条真实存在的 `check()` |
| 单批 | 该批的 op 全部进 `game/tests/contract_ops.json`，每个 op 的每个 `boundaries` 档至少一条用例；四道闸全过 |
| 整件 | `xcheck/COUNT` 的 `covered_sites` ≥ core 候选集的 85%；剩下的逐条在 `xcheck/COVERAGE.md` 里挂 `OK` / `NOTIMPL` / `KNOWN_GAP` / `UNDEFINED` / `OUT_OF_SCOPE` 之一，**没有「未分类」这一档** |

**明确不在范围内的三件**：
① GD 的 `check()` 一条不删 —— 活到 GDScript 内核退役；
② 整局 / 状态机驱动的那一档（计划 §二点五自报 125 条）**不进 L0 也不进 L1**，随 GD 内核退役。
　唯一例外：`t_hit_order` 开头 **4 条** `CWGame.settle_loss(...)` 是纯静态五进一出，摘进批 0（已核：`check(CWGame.settle_loss(10,0,2,1,5) == 15, …)` 等四条）；
③ 测试设施与宿主自测（`t_xcheck` / `t_semkey_single_source` / `t_state_codec` / `t_snapshot` / `t_kernel_*` / `t_obs_*` / `t_mirror_*`）验的是对拍机件本身，留 GD。

### 0.3 契约优先：三族 op，与「什么不许进契约」

这是计划 §二点五风险 1（「契约会把 GD 的内部分解钉死」）**唯一有机制的解法**。
计划只写了一句「缓解：只把 PRD 里本来就有名字的步列进契约」，没有任何东西强制它；
而录制代理天生会「顺手」把私有 `_xxx` 全录下来 —— **实测 `headless_test.gd` 直接调到的模块私有方法有 60 个**
（`_move_cost_mod` 56 次、`_do_move` 53 次、`_aerobic` 19 次、`_move_base_cost` 19 次…；计划书说的是 44 个，**低报了**）。

| 族 | 定义 | op 名从哪来 | expect 形状 |
|---|---|---|---|
| **P（探针）** | 纯查询：不推进流程、不掷骰、不改状态 | PRD 里有名字的量 | `scalar` / `tree` |
| **S（契约步）** | PRD 里有**步号**的一步，会改状态 | PRD 的步号（E 阶段 1~10、S 阶段 1~6） | `delta`（envelope 差分集合） |
| **T（轨迹）** | 其余一切 —— 卡牌结算、私有辅助、连锁 | **没有自己的 op 名**，恒为「它所属的那个契约步名 + `/trace`」 | `delta`，整包不裁 |

**硬机制**（A-3）：`game/tests/contract_ops.json` 是唯一的 op 白名单，两个 runner 与录制代理启动时各做一次双射断言。
表里没有的名字：代理**不覆写**、runner **不分派**、用例**不许引用**。
想给一个私有函数起 op 名，只有一条路 —— 先在 PRD 里给它一个步号，或走 T 族。

**点名禁入白名单**（最可能被顺手录走的一批，实测全部被测试直调）：
`_radiotherapy` / `_tnf` / `_lactic_acid` / `_clonal_growth` / `_remodel` / `_mutation_label` / `_chaos` / `_chaos_return` / `_resolve` —— 一条都不进。

### 0.5 四条纪律

1. **规则代码不许为了测试改行为。** 要暴露内部只走两条：C# 用 `InternalsVisibleTo`（csproj 已有）；GD 直接调 `_xxx`（下划线只是命名习惯，测试设施调得到）。**把 PRD 里有名字的步开成具名函数是允许的，改它做什么不允许。**
2. **GD 原 `check()` 一条不删**，留到 GDScript 内核退役。
3. **不在靶场里重写规则。** 探针一律转调生产代码里已有的入口；loader 里不许有任何算式、不许「推不出来就给个默认值」。（这条今天被违了三处，见 A-2。）
4. **仓库卫生**：一步一提交；**新建文件先提交再做变异检验**（`git checkout` 撤不掉未跟踪文件）；**逐文件 `git add`，不用 `git add -A`**，提交后 `git show --stat` 对一遍；新 `class_name` 先 `godot --headless --path game --import`；`docs/*.md` 与 `.cs` 的批量补丁走 python load/save，**不用 `sed -i`**（Git Bash 会把 CRLF 压成 LF）；GD 测试一律 `tools/run_tests.sh`；会改文件的复核 agent 不共用未提交的工作树。

## A. 机件（八件）

**A-1 ~ A-4 是主路，A-5 ~ A-8 是闸。八件全部落地之前不搬任何一条断言（批 0 除外，见 §B）。**

### A-1 · schema `cwxcase/2`：三类 expect

**落点**
* C#：`core/CellWar.Core.Tests/L0/CaseModel.cs`（`L0Case` 改联合体）、新增 `L0/Expect.cs` + `L0/Subset.cs`、`L0/L0RunnerTests.cs:靶场用例`（按 kind 分派）
* GD：`game/tests/l0_runner.gd:_run_case`、新文件 `game/tests/cw_case_diff.gd`

```jsonc
{
  "schema": "cwxcase/2",
  "id": "e_phase/pressure/stage2_three_adjacent",
  "op": "pressure",                                 // 必须在 contract_ops.json 里
  "covers": ["t_pressure::压迫：二期每相邻癌组织"],  // 回指 GD 原断言 —— 闸三的分子
  "status": "OK",                                   // OK | NOTIMPL | KNOWN_GAP | UNDEFINED | OUT_OF_SCOPE
  "prd":  { "sha": "…", "line": 412, "text": "§E阶段·微环境压迫 —— …" },
  "source": "cw_world.gd:_pressure；RulePolicies.PressureMultiplierByStage = [10,15,20]",
  "harvested_from": "headless_test.gd:t_pressure",  // 录制来的才有
  "world": { /* cwxworld/2，见 A-2 */ },
  "rolls": [],                                      // Tape 带子；[] = 断言「这一步不消耗 rng」
  "args":  { "at": "1,-1" },
  "expect": { "kind": "delta", "changed": { … }, "ignore": [] }
}
```

| kind | 形状 | 判定 | 用在哪 |
|---|---|---|---|
| `scalar` | 裸整数（**今天这 43 条不动，兼容**） | `==` | 批 0 常量 / 批 1 费用 / 批 2 收入 / 批 4 判词 |
| `tree` | 一棵字面 JSON 树 | 逐字段比（C# `L1/DeepDiff.cs:Compare`；GD 新写 `cw_case_diff.gd:compare`） | `quote_path` 的 `{ok,stop,total,left,gained,steps[]}`、坐标数组、`CWData.level_min_memory(4) == [0,10,20,50]` |
| `delta` | **envelope 的差分集合** `{"$.cells[2].energy": 180, …}` | runner 自己算 `diff(env_pre, env_post)`，与 `changed` **整集合比** | S 族全部；计划自报的 716 条「装盘面→变更→比状态」 |

**`delta` 用整集合比、不用包含比**（移植自 harvest，本规格最重要的单条判定规则）：
包含比只钉「该变的变了」，钉不住「不该变的没变」。整集合比同时钉两头 —— C# 多改一个字段红，少改一个字段也红。
**这是录制路线上唯一能机制性地证明「搬的不是空气」的证据**，也是第四道闸在这批上真正有意义的前提。
contract 原稿让人手挑 `select`、再「人工裁掉噪声字段」—— 裁的那一刀正是覆盖面漏出去的地方，而没有任何东西度量裁了多少。**改掉。**

**豁免**：单条用例可带 `ignore: ["$.g.feed_log"]`；**全局豁免表只许有一份**，写死在 `cw_case_diff.gd` 与 `Subset.cs` 的调用点上，内容 = `docs/观测协议_v1.md` §八 的 `known_divergences`（文案 label/prompt/phase_text/win_reason/logs、`cancer_alarm.streak`、`players[].name`、tier B 整块）。

**路径文法**（仓库里没有任何路径语法可借，这里定死；保留 contract 的四条，它比 harvest 的 `$.cells[0]` 序号下标安全）：
* 根恒为 `state`。envelope 元数据（`p` / `rev` / `obs_seq` / `ruleset` / `produced_tiers` / `logs`）**不许出现在 expect 里**。
* 数组一律按**语义键**下标，禁用序号：`cells[<席位>]`、`tiles@<q>,<r>`、`g.events[<事件名>]`、`cells[<席位>].mods[<卡名>]`。

### A-4 · 录制代理（GD 侧）

**落点**：`game/tests/rec/` 下四个代理类 + 一个收割器
`cw_rec_world.gd`（`extends CWWorld`）· `cw_rec_actions.gd`（`extends CWActions`）· `cw_rec_cardfx.gd`（`extends CWCardFx`）· **`cw_rec_worldfx.gd`（`extends CWWorldFx`）** · `cw_recorder.gd` · `harvest.gd`

**第四个类是必须的**（两份草案都漏了）：`cw_world.gd:e_phase` 里步 7 `await game.world_fx.round_effects()` 与步 8 `game.world_fx.tick_durations()` 住在 `CWWorldFx` 上（`cw_game.gd` 的 `var world_fx: CWWorldFx` 是第九个模块之一）。按规矩 1（覆写集合 ≡ 契约面 S 族）不加这个类的话，代理启动当场红，而且不是靠加用例能修的。

**为什么是继承而不是鸭子对象**：`cw_game.gd` 的模块字段是**静态类型**（`var world: CWWorld` / `var actions: CWActions` / `var card_fx: CWCardFx` / `var world_fx: CWWorldFx` …），与刻意留成弱类型、且有护栏断言盯着的 `var rng: Object` 相反。鸭子对象赋不进去。继承还省掉全量转发：只覆写要录的那几个、体内 `super.同名(...)`。

**唯一的换件点**：`cw_game.gd:init()` 是九个模块的**唯一**构造点（逐个 `.new()`，随后 `for m in [setup, world, turn, actions, cards, card_fx, world_fx, cost, damage]: m.game = self`）。代理在 `init()` 之后、开跑之前换四个件并重挂 `.game`。
**已核实无阻碍**：全仓没有 `is CWWorld` / `is CWActions` / `is CWCardFx` / `is CWWorldFx` 一类的类型判断，也没有把 `game.world` 缓存进长寿局部变量的地方。

**六条硬规矩**

1. **只覆写 `contract_ops.json` 里的 S 族。** 启动时用 `get_method_list()` 反射核一遍：覆写集合 ≡ 表里 S 族的 `gd` 入口名，多一个少一个都红。**这条就是契约优先的执行机构**（见 §0.3 的点名禁入清单）。
2. **深度计数，只在深度 0 落一条。** GDScript 覆写是虚派发：`cw_actions.gd` 里对 `enter_tile` 的**裸名自调 6 处**、跨模块 `.enter_tile(` **11 处**，覆写后全打到代理上。忘了深度计数，一次移动会录出嵌套三四条，每条的 pre/post 还都「对」—— 跑 C# 时跟着执行三四次，然后在一个完全无关的字段上报差异。**这类假用例比不录更贵。** 深度 >0 一律丢弃并计数，收割结束打印「丢弃 n 条嵌套」供人对账。
3. **协程性必须镜像父类。** 父函数体内含 `await` 的一律 `await super.f(...)`（`e_phase` 族、`_resolve_camping`、`_tissue_production`、`_vessel_teleport`、`round_effects`、`CWActions` 的 `execute` / `enter_tile` / `_do_move` / `_cascade` …）；不含的直接 `return super.f(...)`（`CWDamage` 全族全文 0 处 `await`，别加）。
4. **rng 一律走 Tape。** 开录前先 `g.rng = XTape.new()`（`game/tests/xcheck_tape.gd`），带子落进用例的 `rolls`；代理自己不调 rng。（harvest 的代理三条规矩里没有这一条，录下来的 `rolls` 会无处可取、`delta` 不可重放。）
5. **装不回去就不录。** 落一条之前先 `cw_case_loader.gd:dump_world(g)`；dump 失败（挂起态 / 多免疫席记忆不等 / 出现 spec 表达不了的键）就往收割报告记一条 `UNLOADABLE`、**不产用例**。这条挡住的正是「闸一悄悄退化成半条」。
6. **正式设施，不是临时件。** 落在 `game/tests/rec/` 下并进 `tools/run_tests.sh`。（`docs/对拍规格_CWX.md` §6 记着 `0239b48` 把临时探针 `_probe_contract_export.gd` 扫进过仓库。）

**收割入口**：`--script tests/harvest.gd -- fn=t_pressure out=…`，产物是 `cwxcase/2` **草稿**，`expect.changed` 是 dump 前后的**整份差分**，**不自动进仓库** —— 人要过一遍 `covers`（回指哪条 `check()`）与 `ignore`（逐条豁免，不是整片裁掉）。

**判据**

* `t_rec_shape`：三个函数的条目数 = 另挂一个纯计数代理对账。
* `t_rec_transparent`：**代理开着跑 `t_pressure` / `t_erosion` / `t_solidify_and_decay`，`CWStateCodec.state_hash` 与不开代理逐位相同**（代理零行为改动的唯一硬证据）。
* `t_rec_contract_only`：覆写集合 ≡ `contract_ops.json` 的 S 族。

## E. 要 Kevin 拍板的（**只列真阻塞的，6 条**）

### E-1 · `delta` 的载体：**envelope 子集，不是 canon 子集**

计划 §二点五写的是「加第三类：**canon 子集逐字段比**（这同时就是 L1 canon 的复用）」。**建议改成 envelope。**

| | canon | envelope |
|---|---|---|
| 生产者 | **只有 C#**（`L1/Canon.cs` + `CanonCodec.cs`；`grep -rli canon game/` 只有 `xcheck_export.gd` 的一句注释） | **两侧都有**（`cw_obs_codec.gd` ↔ `ObservationV1Codec.cs`） |
| 跨内核验过吗 | 没有 —— 判据是**本语言内部**全量往返（`CanonRoundTripTests`） | 验过 —— `EnvelopeParityTests`，**三夹具 573 步 0 差异** |
| 字段纪律 | 无白名单 | `cw_obs_proto.gd` 是白名单，`known_divergences` **只许减不许加**，有版本纪律 |
| 缺什么 | GD 半边**结构上产不出来**：`CanonMod` 十项里的 Stage/Layer/Value/Floor/Requirement 住在 `cw_cost.gd:TEMPLATES` 的静态表里；全部挂起态（`PendingRemodel*` / `PendingLand*` / `WalkOuter` / `PendingDiscardCell`，`Canon.cs` 自己的注释写着「GD 视图里不存在」） | 缺挂起态（以 `ask.kind` 出现）、`cancer_alarm.streak`、`players[].name`、文案 |

canon 相对 envelope 唯一多出来的两样，恰好就是 GD 产不出来的那两块 —— 要补就得改规则代码，纪律 1 不许。

**推荐**：`delta` 按 envelope 子集定义；**canon 继续只当 C# 自己的往返自检，不进跨内核路径**。
**顺带两条裁定**：① `delta` 记**差分集合**、不记两份全量（全量 716 条 × 2 × 约 40 KB ≈ 57 MB；差分约 700 KB。体积实测点：4 人局第 1 回合 GD 42 961 / C# 36 259 字节）；② 判定用**整集合比**、不用包含比（包含比钉不住「不该变的没变」）。
**若否决**（坚持 canon）：GD 侧要新写一个 canon 生产者，而那两块必须改规则代码才产得出来 —— 批 3/5 的用例在 GD 半边装不出 post，闸一天然过不了。不建议。

### E-2 · `cwxworld/2` 的 `cell.mods` 写几元组

**事实**：`cw_game.gd:add_mod` 往实例上写 **5 键** `{name, uses, until, seq, data}`；`cw_obs_proto.gd:MOD` 只导 **4 键**（`data` 不在 envelope 白名单里）；实测 **15 处 `add_mod` 调用点无一传非空 `data`**；C# 的 `ActiveModifier` 要六项（Target / Stage / Layer / Value / Floor / Requirement），而 GD 的 `cond` 是**12 种谓词名的数组**、C# 的 `ModifierRequirement` 只有 **3 值**，join 出来不是 1:1；C# 的技能 / 世界事件 / 趋化源 / 黏液**不存成条目、查询时现算**（`RulePolicies.MoveModifiers`）。

**推荐：四元组 `{name, uses, until, seq}` 打底 + `setup_ops` 前奏兜底。**
* 四元组与 `delta` 的载体（envelope）逐字对齐，不多带一个在差分里永远比不到的 `data`。
* 真正需要「按条装载」的只有 `cw_cost.gd:TEMPLATES` 里 `Store.MOD` 的 **4 张**（【炎症趋化】/【CXCR3趋化】/【上皮—间质转化】/【癌症干性】—— **是 4 张不是 5 张**，【迁移激活】走的是唯一一条 `Store.EVENT_FREE`）加 Flag 类（如「细胞因子网络·待发」）。对这 4~5 张，C# loader 走 `setup_ops`：**照录制到的前奏重放一次 `CardRules` 的打出路径**，不在 loader 里写 `name → ActiveModifier` 工厂（那是靶场里藏第二份规则，纪律 3 不许）。
