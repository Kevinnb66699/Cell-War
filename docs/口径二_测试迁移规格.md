## 〇、口径与完工定义

### 0.1 一句话

把 GD 无头测试里的 **core 规则断言**变成两侧共读的一份 JSON，
**但只有 PRD 里本来就有名字、或本来就有步号的步才配拥有 op 名**；
产出方式以**跑一遍原测试、由录制代理收割**为主，手翻只留录不到的零散条目。

### 0.2 完工定义

| 层级 | 完工条件 |
|---|---|
| 单条用例 | 同一份 JSON，**GD runner 与 C# runner 都绿**，且它的 `covers` 指得到 `game/tests/headless_test.gd` 里一条真实存在的 `check()` |
| 单批 | 该批的 op 全部进 `game/tests/contract_ops.json`，每个 op 的每个 `boundaries` 档至少一条用例；四道闸全过 |
| 整件 | `xcheck/COUNT` 的 `covered_sites` ≥ core 候选集的 85%；剩下的逐条在 `xcheck/COVERAGE.md` 里挂 `OK` / `NOTIMPL` / `KNOWN_GAP` / `UNDEFINED` / `OUT_OF_SCOPE` 之一，**没有「未分类」这一档** |

**明确不在范围内的三件**：
① GD 的 `check()` 一条不删 —— 活到 GDScript 内核退役；
② 整局 / 状态机驱动的那一档（计划 §二点五自报 125 条）**不进 L0 也不进 L1**，随 GD 内核退役。
　唯一例外：`t_hit_order` 开头 **4 条** `CWGame.settle_loss(...)` 是纯静态五进一出，摘进批 0（已核：`check(CWGame.settle_loss(10,0,2,1,5) == 15, …)` 等四条）；
③ 测试设施与宿主自测（`t_xcheck` / `t_semkey_single_source` / `t_state_codec` / `t_snapshot` / `t_kernel_*` / `t_obs_*` / `t_mirror_*`）验的是对拍机件本身，留 GD。

### 0.3 契约优先：三族 op，与「什么不许进契约」

这是计划 §二点五风险 1（「契约会把 GD 的内部分解钉死」）**唯一有机制的解法**。
计划只写了一句「缓解：只把 PRD 里本来就有名字的步列进契约」，没有任何东西强制它；
而录制代理天生会「顺手」把私有 `_xxx` 全录下来 —— **实测 `headless_test.gd` 直接调到的模块私有方法有 60 个**
（`_move_cost_mod` 56 次、`_do_move` 53 次、`_aerobic` 19 次、`_move_base_cost` 19 次…；计划书说的是 44 个，**低报了**）。

| 族 | 定义 | op 名从哪来 | expect 形状 |
|---|---|---|---|
| **P（探针）** | 纯查询：不推进流程、不掷骰、不改状态 | PRD 里有名字的量 | `scalar` / `tree` |
| **S（契约步）** | PRD 里有**步号**的一步，会改状态 | PRD 的步号（E 阶段 1~10、S 阶段 1~6） | `delta`（envelope 差分集合） |
| **T（轨迹）** | 其余一切 —— 卡牌结算、私有辅助、连锁 | **没有自己的 op 名**，恒为「它所属的那个契约步名 + `/trace`」 | `delta`，整包不裁 |

**硬机制**（A-3）：`game/tests/contract_ops.json` 是唯一的 op 白名单，两个 runner 与录制代理启动时各做一次双射断言。
表里没有的名字：代理**不覆写**、runner **不分派**、用例**不许引用**。
想给一个私有函数起 op 名，只有一条路 —— 先在 PRD 里给它一个步号，或走 T 族。

**点名禁入白名单**（最可能被顺手录走的一批，实测全部被测试直调）：
`_radiotherapy` / `_tnf` / `_lactic_acid` / `_clonal_growth` / `_remodel` / `_mutation_label` / `_chaos` / `_chaos_return` / `_resolve` —— 一条都不进。

### 0.5 四条纪律

1. **规则代码不许为了测试改行为。** 要暴露内部只走两条：C# 用 `InternalsVisibleTo`（csproj 已有）；GD 直接调 `_xxx`（下划线只是命名习惯，测试设施调得到）。**把 PRD 里有名字的步开成具名函数是允许的，改它做什么不允许。**
2. **GD 原 `check()` 一条不删**，留到 GDScript 内核退役。
3. **不在靶场里重写规则。** 探针一律转调生产代码里已有的入口；loader 里不许有任何算式、不许「推不出来就给个默认值」。（这条今天被违了三处，见 A-2。）
4. **仓库卫生**：一步一提交；**新建文件先提交再做变异检验**（`git checkout` 撤不掉未跟踪文件）；**逐文件 `git add`，不用 `git add -A`**，提交后 `git show --stat` 对一遍；新 `class_name` 先 `godot --headless --path game --import`；`docs/*.md` 与 `.cs` 的批量补丁走 python load/save，**不用 `sed -i`**（Git Bash 会把 CRLF 压成 LF）；GD 测试一律 `tools/run_tests.sh`；会改文件的复核 agent 不共用未提交的工作树。

**`delta` 用整集合比、不用包含比**（移植自 harvest，本规格最重要的单条判定规则）：

**这是录制路线上唯一能机制性地证明「搬的不是空气」的证据**，也是第四道闸在这批上真正有意义的前提。

**第四个类是必须的**（两份草案都漏了）：`cw_world.gd:e_phase` 里步 7 `await game.world_fx.round_effects()` 与步 8 `game.world_fx.tick_durations()` 住在 `CWWorldFx` 上（`cw_game.gd` 的 `var world_fx: CWWorldFx` 是第九个模块之一）。按规矩 1（覆写集合 ≡ 契约面 S 族）不加这个类的话，代理启动当场红，而且不是靠加用例能修的。

**为什么是继承而不是鸭子对象**：`cw_game.gd` 的模块字段是**静态类型**（`var world: CWWorld` / `var actions: CWActions` / `var card_fx: CWCardFx` / `var world_fx: CWWorldFx` …），与刻意留成弱类型、且有护栏断言盯着的 `var rng: Object` 相反。鸭子对象赋不进去。继承还省掉全量转发：只覆写要录的那几个、体内 `super.同名(...)`。

**唯一的换件点**：`cw_game.gd:init()` 是九个模块的**唯一**构造点（逐个 `.new()`，随后 `for m in [setup, world, turn, actions, cards, card_fx, world_fx, cost, damage]: m.game = self`）。代理在 `init()` 之后、开跑之前换四个件并重挂 `.game`。
**已核实无阻碍**：全仓没有 `is CWWorld` / `is CWActions` / `is CWCardFx` / `is CWWorldFx` 一类的类型判断，也没有把 `game.world` 缓存进长寿局部变量的地方。

**六条硬规矩**

1. **只覆写 `contract_ops.json` 里的 S 族。** 启动时用 `get_method_list()` 反射核一遍：覆写集合 ≡ 表里 S 族的 `gd` 入口名，多一个少一个都红。**这条就是契约优先的执行机构**（见 §0.3 的点名禁入清单）。
