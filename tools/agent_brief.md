# 你要坐下来打一局《Cell War 细胞战争》

这是**桌游的电子化版本**，一局四到六个人，免疫方与癌症方各占一半席位。
你被分到其中一个席位，从头到尾由你操作。**具体是哪一席、通信目录在哪，由派你来的人在提示里给出。**

## 一、先读规则

规则正本：`D:/Projects/SpringSense/2026-2027/Cell War/Cell_War PRD.md`

先通读一遍再落第一子。里面有胜负条件、能量收入、每种细胞的技能、卡牌、世界事件。

**不要读这两类东西**：

- 仓库 `docs/` 下的平衡分析、开发日志、测试报告 —— 那是评测方已有的结论，
  你看了就会照着结论打，这一局也就白打了。
- 引擎源码 `game/scripts/**` —— 真人坐下来只有规则书和桌面。
  照着源码找漏洞打出来的胜率，团队没法拿去改规则。

规则没写清楚的地方，按你的理解打，并在最后的报告里说一句「这里我是这么理解的」。

## 二、怎么行动

**一次工具调用 = 一个决策**：

```
AGENT_TEAM_DIR=<你的队伍目录> bash "<仓库>/tools/agent_turn.sh" <通信目录> <席位号> [上一问的选项下标] [给队友的话]
```

- **第一次调用不带下标**（还没有问题要答），脚本会等到第一个问到你的问题。
- 之后**每次都带上你这一步选的编号**；脚本先替你交上去，再阻塞等到下一个问到你的问题。
- 第四个参数是**队内喊话**，可省。带空格就整个用引号括起来。
- 退出码：`0` = 打印了新的一问，继续打；`3` = 对局结束（打印终局，停下来写报告）；
  `4` = 等超时（对局可能卡住了，停下来报告）；`1` = 用法错。

**不要**去读通信目录里的 `log.txt`、别的队伍的目录、或者别人的 `.seat*.seq` ——
`log.txt` 是各席视角原样拼起来的，等于全场明牌。看了这一局就作废了。

## 三、怎么读一问

```
#123 P0                          ← 问号 + 问的是哪一席（脚本已经替你筛过了）
—— 棋盘 ——                       ← 13×13 的坐标网格，行是 r、列是 q
                                   底色：. 普通组织  + 健康组织  # 癌组织
                                   叠加：数字 = 那一格站着几号玩家的细胞  * = 多个
                                        o 癌巢  m 骨髓  v 血管
  值得注意：(2,-1)/黏液 …          ← 黏液、坏死、新生、存能、存卡（塞不进网格的格子状态）
—— 细胞 ——                       ← ➤ 是你自己的。只有你自己那一行会显示手牌内容、
                                   已装备、修饰、本回合攻了几次抽了几次；
                                   别人只看得到手牌张数（他们看你也一样）
      回合末压迫 至少 1.5          ← 免疫细胞站在这一格，回合末要掉多少能量
—— 全局 ——                       ← 第几世界回合、健康/癌/固化各多少格、抗原记忆、当前事件
—— 掷骰 ——／—— 日志 ——           ← 上一问之后发生了什么
—— 问（action）——                ← 问题类型与提示
   0) 移动→(6, -6)（0.2 能量）     ← 选项。**你要回的就是这个编号**
—— 队内频道 ——                   ← 队友说的话（只有同队看得到）
```

行动选项后面的「⚠压迫 至少 X」是落点在回合末要掉的能量，只给免疫方标。

## 四、认真打

这不是演示，是**要打出真人水平的一局**：团队要用它来判断这套规则平不平衡。
你放水、图省事乱点，整份评估都作废。

- 按你阵营的胜利条件全力争胜，会算的账要算（这一步花多少、换回什么、下一回合对面能做什么）。
- **和队友商量**。真人坐一桌是会说话的 —— 尤其是那种一个人先占位、
  另一个人接着收益的配合，不开口就永远打不出来。
- 一局可能打十几到三十个世界回合，你要落上百步。**每步的思考控制在一两句**，
  想太长会把你自己的上下文撑爆，后半局就没法打了。
- 每次只答一个下标，**不要预先排一串答案** —— 只剩「结束回合」时引擎不问、
  直接收摊，排好的下一个答案会落到下一位玩家头上，把人家的回合白白结束掉。

## 五、打完写报告

拿到退出码 3 之后，写一份**试玩报告**（这才是团队真正要的东西）：

1. 终局：谁赢、怎么赢的（清场 / 占地 / 回合上限）、第几回合。
2. **哪边强**：从头到尾你觉得优势在谁手上？什么时候定的胜负？
3. **能量够不够用**：前期你想做的事做得起吗？被什么卡住了？
4. **强得离谱或者没用的东西**：哪张牌、哪个技能、哪条规则。
5. **胜负手**：哪几步真正决定了这局。
6. 规则里你拿不准、只能按自己理解处理的地方。
