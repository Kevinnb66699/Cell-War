## 文件职责

`catalog.js` 保留原七项文案与已选方向；`immune-*`、`cancer-*`、`common-*` 分别管理两阵营专属及通用技能的三案文案和绘制；`registry.js` 汇总 42 个项目及其绘制器；`draw.js` 管像素基本笔触、素材加载及格子定位；`textures.js` 管骨髓/黏液；`feeding.js` 管吞噬/破裂；`combat.js` 管猎杀/中和/光剑；`app.js` 管筛选、播放、选款与导出；`serve.js` 提供本地静态服务。

Canvas 320×200、最近邻、整数笔触、12fps。此目录是设计草稿，不参与 Godot 规则或场景。四种效应应答齐全。示意路径不是真实自动结算，接入时逐项消费引擎结果。

R3 共 42 个项目、126 个方案，其中 40 项为技能或效应、2 项为组织纹理。首次默认黏液破裂 A、Excalibur B、中和抗体 A（飞行与新双环），并保留用户原页面已选的黏液纹理 A。之后保留用户本地改选。其他项不擅自定稿。仍沿用 `cellwar-art-r2` 存储键，确保 R2 本地选择可直接延续。

黏液破裂在破裂后由中心向外逐像素揭示，黏液覆盖与扩散前沿共用同一个半径，不再整格提前出现。页面允许搜索、按阵营筛选、播放/暂停、慢放、拖动时间、显示棋盘、逐项选择/取消、复制清单与 JSON 备用文本。系统开启减少动态时默认暂停。JSON 文件下载取决于浏览器支持，始终提供可复制文本。本轮不修改或接入任何 Godot 游戏脚本。
