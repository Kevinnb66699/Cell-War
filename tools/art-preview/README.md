# Cell War 像素美术选稿 R2

仓库根目录执行 `bun tools/art-preview/serve.js`，打开 http://127.0.0.1:4317/tools/art-preview/index.html 。只监听本机，不安装依赖。

## 本轮用户决策

- 连续吞噬：吃豆人式强烈吞咬 + 持续强化粒子，三案重画。
- 免疫猎杀：全局大瞄准标搜索、收缩、捕获，三案重画；不显示 lock 文案或脚下水平圈。
- 黏液破裂：保留 A，追加喷射与环压雨落两案，落地统一为 A 液膜。
- Excalibur：保留 B 双螺旋。
- 中和抗体：A 的 Y 形抗体飞行，抵达后两个固定直径的双向环绕封禁环。
- 骨髓：去紫色，三案改用骨白、灰绿、浅褐与髓红。未来同步库存进度环及固化族。
- 细胞必须站在格子顶面，所有落点经统一轴坐标投影，只有迁移过程经过格间。

## 文件职责

`catalog.js` 文案与已选方向；`draw.js` 像素基本笔触、素材加载及格子定位；`textures.js` 骨髓/黏液；`feeding.js` 吞噬/破裂；`combat.js` 猎杀/中和/光剑；`app.js` 播放、选款与导出；`serve.js` 本地静态服务。

Canvas 320×200、最近邻、整数笔触、12fps。此目录是设计草稿，不参与 Godot 规则或场景。四种效应应答齐全。示意路径不是真实自动结算，接入时逐项消费引擎结果。

R2 首次默认黏液破裂 A、Excalibur B、中和抗体 A（飞行与新双环），并保留用户原页面已选的黏液纹理 A。之后保留用户本地改选。其他项不擅自定稿。选款存于 `cellwar-art-r2`，不覆盖旧版选稿。

页面允许播放/暂停、慢放、拖动时间、显示棋盘、逐项选择/取消、复制清单与 JSON 备用文本。系统开启减少动态时默认暂停。JSON 文件下载取决于浏览器支持，始终提供可复制文本。
